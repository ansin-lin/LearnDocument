# Python 数据分析课程规则

## 学习路线

- 按 NumPy 数组基础 → Pandas Series/DataFrame → 读取数据 → 清洗与类型 → 筛选与转换 → 分组聚合 → 合并 → 时间序列 → 可视化 → 分析项目推进。
- 使用小而可检查的数据建立单点能力，再进入真实文件和综合分析。

## 技术底线

- 展示输入数据、转换步骤以及结果的形状、列名、类型和关键值。
- 明确缺失值、重复值、异常值、日期解析、字符串编码和数值类型转换的处理策略。
- 区分视图与副本、索引与位置、逐行处理与向量化；不把性能建议绝对化。
- 聚合和连接说明分组键、连接键、基数及行数变化，避免无意重复或丢失数据。
- 图表说明坐标、单位、聚合口径和可能造成误导的截断或比例。

## 项目与验证

- 分析项目说明问题、数据来源、字段含义、清洗规则、计算口径、输出和可复现步骤。
- 结论必须能追溯到代码和数据，不根据图表外观编造业务因果。
