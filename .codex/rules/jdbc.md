# JDBC 课程规则

## 学习路线

- 按驱动与连接 → PreparedStatement → 查询结果 → DML → 事务 → 批处理 → 连接池 → DAO/Repository → 异常与资源管理推进。
- 先使用最小程序观察连接、参数、结果和提交，再进入分层项目。

## 技术底线

- 使用 try-with-resources 管理 Connection、Statement 和 ResultSet，说明关闭顺序和连接池代理差异。
- 优先 PreparedStatement 参数绑定，不通过字符串拼接外部输入构造 SQL。
- Java 类型、SQL 类型、列名、空值和时间类型转换必须一致，说明 `wasNull()` 等边界。
- 默认自动提交行为必须明确；事务示例说明开始、提交、回滚、异常和资源释放。
- 批处理说明部分失败、返回结果和事务范围；连接池说明容量、超时、泄漏和健康检查。

## 项目与验证

- 提供数据库、驱动版本、建表数据、连接配置和运行方法；凭据使用占位或环境配置。
- DAO/Repository 只负责持久化契约，不在示例中隐藏业务事务或吞掉 SQL 异常。
