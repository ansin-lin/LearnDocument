# Python 自动化课程规则

## 学习路线

- 按文件与目录 → CSV/Excel → 命令行参数 → 外部命令 → HTTP 接口 → 浏览器自动化 → 调度与批处理 → 自动化项目推进。
- 先完成可重复的小任务，再组合跨文件、接口和浏览器的流程。

## 技术底线

- 说明输入、输出、运行目录、重复执行结果和失败后的恢复方式。
- 写操作优先设计幂等性、预览模式、备份或临时文件；破坏性操作限制范围并要求明确确认。
- 外部命令检查退出状态、标准输出和标准错误；网络请求设置超时与有限重试。
- 浏览器自动化使用稳定定位，处理等待、登录状态、下载和页面变化，不依赖固定休眠作为主要同步手段。
- 定时和批处理说明日志、锁或重复运行、退出码、凭据、告警和中断恢复。

## 项目与验证

- 自动化项目提供样例输入、预期输出、失败案例、重复执行测试和清理步骤。
- 企业任务加入操作记录、错误汇总和人工复核点，不把自动执行等同于可以无人监管。
