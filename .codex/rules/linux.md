# Linux 课程规则

## 学习路线

- 按终端与文件系统 → 文件目录 → 文本查看 → 用户组与权限 → 进程 → 网络 → 软件包 → 服务与日志 → 存储 → 故障排查推进。
- 标明发行版、版本和权限身份；区分通用概念与发行版命令。

## 技术与安全边界

- 区分绝对/相对路径、文件/目录、用户/组、读写执行权限、进程/服务和内核/用户空间。
- 命令说明当前目录、输入对象、输出和退出状态；通配符、递归和权限提升前解释匹配范围。
- 删除、权限变更、结束进程、磁盘和系统配置操作必须限制目标并说明恢复方法。
- 服务和日志示例说明 systemd 或其他管理器前提，不把日志文件路径绝对化到所有系统。

## 现场任务

- 练习包含状态确认、日志调查、端口/进程检查、权限问题和安全变更，不只要求记忆命令。
