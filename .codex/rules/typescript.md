# TypeScript 课程规则

## 学习路线

- 在 JavaScript 基础之后，按类型标注 → 联合与收窄 → 对象和接口 → 函数 → 泛型基础 → 模块 → DOM/框架类型 → 配置与构建推进。

## 技术底线

- 类型用于静态检查和开发工具，不是运行时数据校验；外部输入仍需运行时验证。
- 优先类型推断和明确业务类型，避免无目的 `any`、过度断言和复杂泛型。
- 区分 `unknown`、`any`、`never`、可选属性、空值和联合类型，并通过控制流收窄。
- 接口与类型别名按表达需求选择，不使用绝对化规则；泛型说明类型参数与输入输出关系。
- `tsconfig`、模块系统、目标环境和构建工具保持一致，说明源代码与生成 JavaScript 的关系。

## 框架与项目

- 框架示例先讲最常用 Props、事件、状态和 API 数据类型，再进入通用组件和高级类型技巧。
- API 类型必须与实际响应和错误状态一致，不用类型断言掩盖契约差异。
