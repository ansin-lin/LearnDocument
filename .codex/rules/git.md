# Git 课程规则

## 学习路线

- 按配置与仓库 → 工作区/暂存区/提交 → 查看历史 → 分支与合并 → 远程同步 → 冲突与 Review → 撤销恢复 → 标签发布 → 高级操作推进。
- 高级操作前讲清工作区、暂存区、仓库、提交、分支、远程和 HEAD。

## 安全边界

- 区分通过新提交修正与改写历史；`reset`、`rebase`、强制推送和清理操作说明影响范围、协作风险和恢复方法。
- 每个操作说明前置状态、命令后的状态和验证命令，不只给命令列表。
- PowerShell、Bash 和 Command Prompt 使用各自正确代码块，不混用语法。
- 不在示例仓库中提交密钥、大文件或生成物；说明 `.gitignore` 不能移除已经跟踪的秘密。

## 团队协作

- 强调小提交、清晰提交信息、分支策略、Pull Request、冲突处理、Review 和验证证据。
- SES 任务覆盖拉取既有代码、创建分支、改修、自测、回应指摘和安全同步，而不只训练新建仓库。
