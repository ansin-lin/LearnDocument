# HTML 课程规则

## 学习路线

- 按文档结构 → 文本与链接 → 图片与媒体 → 列表与表格 → 表单 → 语义结构 → 可访问性与元数据推进。
- 先建立浏览器解析和元素嵌套概念，再进入页面结构和表单任务。

## 技术底线

- 使用语义元素表达内容职责，不用 `div` 和视觉样式代替标题、按钮、列表、表格或表单控件。
- 标签嵌套、属性、相对/绝对路径、表单名称和值必须与提交行为一致。
- 表格用于表格数据，不用于页面布局；图片提供合适替代文本，装饰图片使用空替代文本。
- 表单控件具有可关联的 label、明确类型、名称和必要提示；HTML 校验不能替代后端校验。
- 可访问性优先使用原生语义，再按需使用 ARIA，不用 ARIA 修补可由正确标签解决的问题。

## 验证

- 示例提供完整 HTML 文档或明确插入位置，并通过浏览器、开发者工具和键盘操作检查结构与行为。
