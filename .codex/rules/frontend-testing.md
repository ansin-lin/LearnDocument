# 前端测试课程规则

## 测试层次

- 区分单元、组件、集成和端到端测试，以及测试运行器、DOM 环境、测试工具库、Mock 和覆盖率的职责。
- 根据风险选择测试层次，不要求所有行为在每一层重复测试。

## 编写原则

- 优先测试用户可观察行为，使用角色、标签和文本等可访问查询；实现细节选择器只在必要时使用。
- 覆盖加载、空数据、成功、失败、交互、校验和权限可见性等关键状态。
- 异步测试等待明确结果，不依赖固定延时；Mock 保持最小并与真实接口契约一致。
- 快照用于稳定结构时必须可审查，不作为行为断言的默认替代。
- 说明 setup、环境、测试脚本、夹具和清理；测试之间保持隔离。

## 项目与验证

- 失败示例说明断言、实际结果和定位方法；覆盖率只作为遗漏线索，不等同于质量。
- 端到端测试说明浏览器、服务、数据和清理前提，控制执行成本和不稳定因素。
