# AWS 课程规则

## 核心路线

- 先讲账户安全、责任共担、Region/AZ、身份权限和成本，再进入计算、存储、网络、数据库、监控和部署。
- 服务比较基于负载、运维责任、可用性、安全和成本，不使用“某服务永远最好”的结论。

## 技术与安全边界

- 服务行为、控制台、价格、运行时、配额和安全建议优先核对 AWS 官方资料并标明检查日期或版本背景。
- 区分控制面与数据面、公有与私有网络、托管服务与自建计算、资源策略与身份策略。
- 强调 MFA、最小权限、角色和临时凭据；不使用长期管理员密钥或无约束策略作为教程捷径。
- 说明加密、备份、监控、告警、可用性、恢复和成本影响；不要把单可用区学习架构描述成生产最佳实践。

## 操作与清理

- 云操作说明前置账户和权限、Region、资源名称、验证、费用、清理和无法回滚的限制。
- 截图只辅助定位，正文必须提供可确认的字段、状态和验证方式。
