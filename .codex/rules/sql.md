# SQL 课程规则

## 路线与方言

- 按关系与表 → 查询基础 → 条件与排序 → 函数 → 聚合分组 → 连接与子查询 → DML → DDL 与约束 → 索引 → 事务 → 执行计划推进。
- 标明数据库产品和版本，或明确哪些是标准 SQL、哪些是方言；同组课程保持表结构和样例数据一致。

## 技术底线

- 非直观查询展示结果表，并区分 SQL 书写顺序与逻辑执行顺序。
- 准确讲解 `NULL` 三值逻辑、连接基数、重复行、聚合/分组、约束和事务一致性。
- 企业示例避免无目的 `SELECT *`，字段、别名、连接条件和排序具有明确意图。
- 索引结论结合查询条件、数据分布、写入成本和执行计划，不使用绝对化经验法则。
- DDL、DML、权限和事务行为按数据库方言说明，不混用产品语法。

## 数据与安全

- 写操作说明初始数据、影响范围、事务和回滚；删除或结构变更提供备份和恢复边界。
- 参数化查询与字符串拼接分开讲解，不在应用示例中制造 SQL 注入。
