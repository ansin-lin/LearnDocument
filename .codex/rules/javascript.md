# JavaScript 课程规则

## 学习路线

- 按值与变量 → 运算和流程 → 函数与作用域 → 数组与对象 → DOM 与事件 → 模块 → 异步与网络 → 错误处理 → 测试与工程化推进。
- 先掌握语言和浏览器基础，再进入框架；不依赖框架掩盖 JavaScript 概念。

## 技术底线

- 准确区分原始值与对象、严格相等、真值判断、作用域、闭包、`this`、同步调用栈和事件循环。
- DOM 示例使用语义元素和稳定查询，说明事件对象、传播、默认行为和监听器生命周期。
- Promise、`async`/`await` 和网络请求包含成功、失败、超时或取消边界，不吞掉异常。
- 使用 ES 模块时说明运行环境、导入路径和构建前提；浏览器与 Node.js API 不混为一谈。
- 不在浏览器代码中保存真实秘密；前端校验和隐藏按钮不能替代服务端安全控制。

## 示例与调试

- 示例展示输入、状态变化和可观察输出，使用控制台、断点、Network 和 Elements 定位问题。
- 高级原型、复杂闭包技巧和底层事件循环细节按难度后置。
