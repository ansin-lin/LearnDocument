# MyBatis 课程规则

## 学习路线

- 按数据源与会话 → Mapper 接口 → 参数绑定 → 结果映射 → XML/注解 SQL → 动态 SQL → 关系查询 → 事务 → 性能与缓存推进。
- 零基础主线保持一种稳定的构建、配置和 Mapper 组织方式，替代路线放入扩展内容。

## 技术底线

- Java 类型、Mapper 方法、XML/注解、SQL 参数、列名和结果映射保持一致。
- 准确区分 `#{}` 参数绑定与 `${}` 文本替换，并说明后者的 SQL 注入风险和有限使用场景。
- 说明 SqlSession、Mapper 代理和事务的生命周期；与 Spring 集成时明确事务由谁管理。
- 动态 SQL 说明空条件、集合参数、生成 SQL 和边界；关系查询说明 N+1、连接和嵌套映射取舍。
- 缓存说明作用域、失效和一致性限制，不把启用缓存视为通用优化。

## 项目与验证

- 提供建表和样例数据，展示实际 SQL、参数、结果和异常；多层项目保持 DTO、实体和数据库字段一致。
- 框架章节只回顾必要 SQL，通用 SQL 原理链接 SQL 课程。
