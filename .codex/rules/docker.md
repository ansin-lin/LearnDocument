# Docker 课程规则

## 学习路线

- 按镜像与容器 → Dockerfile → 构建缓存 → 端口和环境变量 → 卷 → 网络 → Compose → 日志与排错 → 安全和发布推进。

## 技术底线

- 区分镜像、容器、仓库、卷和网络；容器停止、删除和镜像删除的数据影响分别说明。
- Dockerfile 使用明确基础镜像版本、工作目录、依赖缓存、非 root 用户和合理入口；不把秘密写入镜像层。
- 解释构建时与运行时、`CMD` 与 `ENTRYPOINT`、端口声明与发布、绑定挂载与命名卷。
- Compose 服务、环境、网络、依赖和健康检查与应用实际启动契约一致。

## 验证与安全

- 示例提供构建、启动、日志、健康检查、停止和清理命令，并说明持久化数据是否保留。
- 生产内容说明镜像扫描、最小权限、只读文件系统、资源限制和日志，不把本地 Compose 等同于生产平台。
