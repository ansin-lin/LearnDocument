# Spring Boot 课程规则

## 主线定位

- 先建立请求 → Controller → Service/Application → Repository/Mapper → 数据库 → 响应的处理流，再进入验证、事务、异常、认证、日志、测试和部署。
- Spring 项目前先用最小示例讲清 Bean、依赖注入、配置、请求处理和事务入口。

## 技术底线

- 区分依赖注入与对象创建、配置与业务逻辑、DTO 与实体、参数校验与业务规则、HTTP 错误与内部异常。
- 工程示例优先构造器注入、明确事务边界、统一异常处理、分环境配置、结构化日志和自动化测试。
- 注解说明使用位置、处理者、触发时机和运行效果；Spring Boot 3 使用兼容的 Jakarta 命名空间及依赖。
- 凭据通过配置、环境变量或密钥管理占位，并说明本地设置和生产边界。

## 项目连续性

- 包名、分层、DTO、实体、字段、接口、配置和错误结构跨章节保持一致。
- 多文件示例说明请求、校验、事务、映射和异常转换的责任层。
- 最终项目提供构建、运行、数据库准备、测试、配置和验收，不把 IDE 启动成功当作交付完成。
