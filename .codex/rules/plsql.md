# PL/SQL 课程规则

## 学习路线

- 按匿名块 → 变量与类型 → 条件循环 → SQL 嵌入 → 异常 → 游标 → 过程与函数 → 包 → 触发器 → 批处理与动态 SQL 推进。
- 使用 Oracle 术语和可执行语法；客户端需要时保留代码块后的 `/`。

## 技术底线

- 区分 SQL 数据操作与 PL/SQL 过程控制，说明作用域、变量赋值和异常传播。
- 准确说明 `%TYPE`、`%ROWTYPE`、隐式/显式游标、参数模式、包规范与包体。
- 存储过程通过 OUT 参数、游标或约定结构传递结果；除非事务契约要求，不在可复用过程内隐藏 `COMMIT`。
- 动态 SQL 说明绑定变量和注入风险；批处理说明集合、异常和部分失败处理。
- 触发器和调度说明隐式执行、副作用、排查和维护成本，不作为普通业务逻辑默认位置。

## 项目与验证

- 示例说明表结构、权限、执行工具、输出设置和事务状态，并展示调用与结果。
- 与 Java/MyBatis 集成时明确参数、类型、事务和异常转换契约。
