# 部署与运维课程规则

## 学习路线

- 按构建产物 → 运行时配置 → 进程/服务 → 反向代理与 TLS → 数据库迁移 → 日志监控 → 发布 → 回滚 → 备份恢复推进。
- 区分本地开发、测试、预发布和生产环境，以及手工学习步骤与可重复部署流程。

## 技术底线

- 说明应用服务器、Web 服务器、端口、域名、DNS、证书、网络和数据库各自职责。
- 配置与秘密分离，明确环境变量、配置文件和密钥管理边界；不在仓库或镜像保存真实凭据。
- 发布步骤包含构建、依赖、迁移、静态资源、健康检查、流量切换、监控和回滚条件。
- 数据库迁移、文件存储和缓存变更说明兼容顺序、备份和不可逆风险。
- 日志、指标、告警和追踪服务于故障定位；不把“进程正在运行”当作业务健康。

## 运维任务

- 练习提供初始环境、部署、验证、故障注入、回滚和清理；说明权限、成本和停机影响。
- 交付包含依赖、配置项、启动停止、验证、日志位置、已知限制和恢复步骤。
