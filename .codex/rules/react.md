# React 课程规则

## 主线定位

- 在 HTML、CSS、JavaScript 基础后，主线使用函数组件与 Hooks；类组件用于阅读既有项目时再讲。
- 保持一套稳定的 React、构建工具、路由和状态方案，替代库放入扩展内容。

## 核心路线

- 按组件与 JSX → Props → State → 事件与表单 → 条件和列表 → Effect → 组件组合 → 路由 → API → 状态管理 → 测试与部署推进。
- 先用最小组件讲清渲染、状态更新和数据流，再组合复杂页面。

## 技术底线

- 状态更新按快照和批处理解释，不把 setState 描述为同步修改变量。
- Effect 用于与外部系统同步，依赖和清理与实际行为一致；不把 Effect 当作普通派生计算工具。
- 列表使用稳定 key；表单明确受控或非受控方式；Props 不直接修改。
- 组件拆分根据职责、复用和状态归属，不为形式制造过度抽象。
- API 页面处理加载、空数据、成功、失败和卸载后的请求边界。

## 项目边界

- 组件、路由、状态、类型、API 契约和样式策略跨章节一致。
- 最终项目提供依赖、环境配置、构建、测试和验收，不只展示页面截图。
