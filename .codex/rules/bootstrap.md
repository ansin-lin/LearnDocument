# Bootstrap 课程规则

## 主线内容

- 先理解容器、网格、断点和工具类，再进入表单、导航、卡片、模态框等组件。
- 标明 Bootstrap 主要版本、CSS/JavaScript 引入方式及 Popper 等必要依赖；不混用不同大版本写法。

## 技术边界

- 网格建立在容器、行和列的有效层级上；断点类说明从哪个宽度开始生效。
- 工具类用于常见约束，不以大量互相覆盖的类替代清楚的自定义样式。
- 交互组件说明初始化方式、必要属性、事件和可访问性，不只复制标记。
- 自定义主题和覆盖样式说明加载顺序、变量或构建前提。

## 项目应用

- 组件选择服务于页面任务，并检查移动端、键盘、错误状态和长内容。
