# Java 课程规则

## 路线与版本

- 默认 Java 17；使用其他版本、预览特性或更新语法时明确要求。
- 按环境与编译运行 → 类型和流程控制 → 数组与字符串 → 方法 → 类与对象 → 继承与接口 → 异常 → 集合与泛型 → I/O → 测试 → 并发与高级专题推进。

## 技术底线

- 讲清源码、字节码、JDK/JVM/JRE、编译期与运行期、基本类型与引用类型、值传递、作用域和对象生命周期。
- 类名使用 PascalCase，方法和变量使用 camelCase，常量使用 UPPER_SNAKE_CASE，包名使用小写。
- 可运行示例包含导入、外层类及 `main` 或测试入口，并与文件名一致。
- 准确区分受检与非受检异常，不鼓励空 `catch`、无差别捕获或用异常代替正常流程。
- 集合先讲接口、实现、泛型、遍历和选择；Stream、反射、并发、JVM 内部和复杂泛型按难度后置。

## 企业应用

- 练习从编写新代码逐步过渡到阅读、修改、调试和测试既有代码。
- 说明包结构、依赖、日志、单元测试、编码规范和 Review 对当前示例的实际影响。
