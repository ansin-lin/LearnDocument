# Vue 课程规则

## 主线定位

- 在 HTML、CSS、JavaScript 基础后，以一套稳定的 Vue 版本、构建工具和 API 风格推进。
- Composition API 与 Options API 不无说明混用；主线选定一种，另一种用于阅读既有项目或扩展比较。

## 核心路线

- 按应用与组件 → 模板与响应式状态 → 计算属性和侦听 → Props 与事件 → 表单 → 生命周期 → 路由 → 状态管理 → API → 测试与部署推进。
- 先用最小组件说明响应式、模板绑定和组件通信，再组合路由、状态和接口。

## 技术底线

- 区分 `ref`、`reactive`、计算属性和副作用；不使用 watch 代替可以直接派生的状态。
- Props 单向传递，子组件通过事件或明确模型更新契约通知父组件；列表使用稳定 key。
- 生命周期和清理与实际资源关联，避免在 setup 或渲染过程中产生不可控副作用。
- API 页面处理加载、空数据、成功和失败，路由参数和状态刷新行为可验证。

## 项目边界

- 组件边界、状态归属、类型、路由名、API 契约和样式策略跨章节一致。
- 最终项目提供依赖、环境配置、构建、测试和验收，不只展示页面截图。
