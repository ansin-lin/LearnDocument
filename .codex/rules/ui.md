# UI 与组件库课程规则

## 学习边界

- 先掌握 HTML 语义、CSS 布局、响应式和可访问性，再学习组件库 API。
- 区分设计系统、CSS 框架、组件库和图标库；组件库不能替代页面结构和交互设计。

## 设计与实现

- 使用明确的间距、颜色、字体、断点和状态规范，避免无解释的魔法值。
- 页面覆盖默认、加载、空数据、错误、禁用、焦点和移动端状态。
- 包装组件仍保留语义 HTML、键盘操作、焦点管理和可访问名称。
- 组件层级、主题 Provider、样式入口和依赖版本必须满足官方结构要求。

## 项目与验收

- UI 示例说明目标、布局约束、组件选择和响应式行为，不只复制视觉效果。
- 验收同时检查不同宽度、键盘操作、长文本、错误信息和基础对比度。
