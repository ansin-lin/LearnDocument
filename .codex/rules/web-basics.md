# Web 基础课程规则

## 核心路线

- 先建立“浏览器发出请求 → 网络传输 → Web/应用服务器处理 → 数据库或外部服务 → 返回响应”的完整路径。
- 区分浏览器、前端、后端、Web 服务器、应用服务器、数据库、DNS、HTTP、TLS、API、反向代理、负载均衡和缓存。
- HTTP 先讲请求方法、URL、请求头、请求体、状态码和响应体，再进入 JSON、REST、Cookie、Session、认证授权和 CORS。

## 技术边界

- 区分认证与授权、Cookie 与 Session、同源限制与后端权限、HTTP 与 HTTPS。
- REST 是接口设计风格，不等同于 JSON、HTTP 或某个框架。
- 概念图与可部署配置分开；简化图必须说明省略的组件。
- 语言和框架课程链接 Web 基础主要说明位置，只回顾当前任务需要的概念。

## 练习与验证

- 使用浏览器开发者工具、HTTP 客户端或最小服务观察真实请求和响应。
- 练习包含读取请求、解释状态码、定位前后端责任和判断常见错误所在层。
