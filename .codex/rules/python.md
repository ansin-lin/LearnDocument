# Python 课程规则

## 路线与范围

通用路线：环境与虚拟环境 → 基础语法与容器 → 字符串与编码 → 函数与类型提示 → 迭代器与生成器 → 异常、调试与上下文管理 → 面向对象 → 模块与标准库 → 文件与数据处理 → 测试与 Git → 方向课程 → 项目实战。

基础路线应覆盖安装、`pip`、变量与类型、流程控制、`list/tuple/dict/set`、字符串、函数、异常、`with`、类、模块、文件、JSON/CSV/Excel 和测试基础。闭包、复杂装饰器、元类、描述符及对象模型细节通常为后续了解。

## 技术底线

- `with` 是上下文管理，不只属于异常处理。
- `readline()` 每次读取一行；`for line in file` 自动逐行迭代；`writelines()` 不自动添加换行。
- `flush()` 推进缓冲数据，不代表已经物理写入磁盘。
- `ensure_ascii=False` 控制 JSON 中 Unicode 的显示，不修复源数据编码错误。
- CSV 与 Excel 是不同格式；`openpyxl` 主要处理工作簿，`pandas` 主要用于分析和批量表格处理。
- `requests` 是 HTTP 客户端；请求必须设置 `timeout` 并包含基础异常处理。
- 类型提示用于可读性和静态检查，不是运行时强制类型限制；首次只讲基础标注。
- 文本文件使用 `encoding="utf-8"`，路径优先使用 `pathlib.Path`，代码使用 4 空格缩进和明确英文名称。

## 方向课程

- Python 通用基础只建立各方向共享的语言、标准库、文件、数据库访问和测试能力。
- Web、数据分析和自动化进入方向课程后，分别加载对应专项规则；不在通用基础中提前展开完整方向知识。
- 一条零基础 Web 主线只选择一个主要框架；其他框架作为独立路线或学完主线后的比较专题。

## 框架与库侧重

- 基础说明优先覆盖导入方式、核心函数/类/方法/属性、输入输出、异常，以及同步/异步或上下文管理要求。
- Pandas、Web 框架和自动化库进入项目应用前，先用最小数据、请求或文件完成单点示例。

不要堆砌无关第三方库，也不为炫技提前引入高级语法。
