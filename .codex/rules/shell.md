# Shell 脚本课程规则

## 学习路线

- 按命令与参数 → 变量和引用 → 输入输出与管道 → 条件 → 循环 → 函数 → 参数解析 → 错误处理 → 日志与自动化任务推进。
- 明确 Bash、PowerShell 或其他 Shell；不同语法分开示例。

## 技术底线

- 说明 shebang、执行权限、直接执行与显式调用解释器的区别。
- 正确引用变量和路径，解释分词、通配符、命令替换、重定向和管道的执行效果。
- 检查命令退出状态；Bash 的 `set -e`、PowerShell 的错误行为等需说明限制，不作为完整错误处理替代。
- 输入参数校验、临时文件、并发、重复执行、日志和清理与任务风险匹配。
- 破坏性操作支持预览、限制目录或明确确认，不拼接未经校验的输入执行命令。

## 验证

- 脚本练习提供正常输入、边界输入、失败命令、退出码和重复执行结果。
