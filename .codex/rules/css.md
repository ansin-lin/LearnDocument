# CSS 课程规则

## 学习路线

- 按选择器与层叠 → 盒模型 → 常见属性 → 定位 → Flexbox → Grid → 响应式 → 变量与组织 → 动画和高级专题推进。
- 先解释正常文档流、继承、层叠和盒模型，再使用布局技巧。

## 技术底线

- 区分选择器优先级、源码顺序、继承和 `!important`；不把提高优先级作为默认修复方法。
- 说明 `box-sizing`、宽高、内外边距、溢出和格式化上下文对布局的影响。
- Flexbox 用于一维布局，Grid 用于二维布局；根据内容和约束选择，不以框架类名替代原理。
- 响应式从内容和断点需求出发，检查不同宽度、缩放和长文本，不只适配单一截图。
- 颜色、焦点、动画和隐藏内容考虑对比度、键盘操作和减少动态效果偏好。

## 工程边界

- 示例明确样式作用范围、加载顺序和 HTML 前提；避免无解释的魔法数和全局污染。
- 组件库样式问题先检查层叠、主题和 DOM 结构，再使用覆盖规则。
