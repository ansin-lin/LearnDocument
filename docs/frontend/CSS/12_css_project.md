# CSS 新人综合练习：有給休暇申請システム

本章使用统一的前端递进练习第 2 阶段。

请打开并完成：[CSS 递进练习：有給休暇申請システム](../training/02_css_task.md)。

## 1. 本阶段完成目标

你需要继续使用 HTML 阶段完成的七个页面，为系统添加统一样式。CSS 阶段要同时处理公开认证页面和登录后的业务页面。

最终目录应扩展为：

```text
paid-leave-system/
├─ login.html
├─ register.html
├─ index.html
├─ apply.html
├─ confirm.html
├─ complete.html
├─ applications.html
└─ css/
   └─ style.css
```

七个页面共用一个 `css/style.css`。本阶段只处理 CSS 表现层，不添加 JavaScript，不实现注册、登录、数据保存、筛选、取消和动态页面传值。

本阶段的样式目标：

| 页面范围 | 样式重点 |
| --- | --- |
| `login.html`、`register.html` | 居中的认证卡片、清楚的表单层级、主次操作区分 |
| `index.html`、`apply.html`、`confirm.html`、`complete.html`、`applications.html` | 登录后页眉、导航、信息面板、表单、按钮、状态标签和表格 |
| 全部页面 | 统一颜色、字体、间距、焦点状态、响应式和长文本处理 |

## 2. 学习方式

请按练习文件中的任务顺序完成：

1. 先让七个页面正确加载同一个外部 CSS 文件。
2. 再完成全局盒模型、字体、颜色、版心和间距。
3. 完成登录页和注册页的认证卡片样式。
4. 统一登录后业务页的页眉、导航、面板、按钮、表单和表格样式。
5. 最后完成响应式、键盘焦点、长文本和缩放检查。

CSS 阶段必须基于 HTML 阶段的语义结构继续修改。可以添加必要的 `class`，但不要把正确的语义标签全部替换成 `div`。

## 3. 验收重点

提交前至少确认：

- 七个页面都正确加载 `css/style.css`。
- 登录和注册页没有显示登录后导航。
- 认证页与业务页风格统一，但页面职责清楚。
- 没有行内样式、`style` 标签、CSS 框架或组件库。
- 页面在 360px、768px、1280px 宽度下都能阅读和操作。
- 浏览器缩放到 200% 后，正文、按钮和表单控件不重叠。
- 链接、按钮和表单控件有清楚的键盘焦点状态。
- 状态、必填和完成结果不只依赖颜色表达。
