# Node.js 与 npm 基础

本课程是 TypeScript、Vite、Vue、React 和前端工程化之前的工具基础。重点不是开发 Node.js 后端，而是理解前端项目为什么需要 Node.js、npm、项目依赖和脚本命令。

## 学习成果

完成后应能够：

- 区分浏览器 JavaScript 与 Node.js；
- 说明 Node.js 在前端项目中的作用；
- 使用 npm 创建项目并安装依赖；
- 阅读 `package.json`；
- 区分普通依赖和开发依赖；
- 说明 `node_modules` 与锁定文件的作用；
- 使用 npm scripts 和 npx 运行项目工具；
- 根据项目文件恢复依赖；
- 排查常见的目录、版本和命令问题。

## 课程边界

本课程只讲前端开发所需的 Node.js 工具基础，不讲：

- Node.js HTTP 服务；
- Express、NestJS；
- 数据库访问；
- 服务端认证；
- 文件上传；
- Node.js 后端部署。

后续需要开发 Node.js 后端时，应进入独立的 Node.js 服务端课程。
