# HTML 新人综合练习：有給休暇申請システム

本章使用统一的前端递进练习第 1 阶段。

请打开并完成：[HTML 递进练习：有給休暇申請システム](../training/01_html_task.md)。

## 1. 本阶段完成目标

你需要只使用 HTML 制作七个页面，完成“公开认证页面 + 登录后业务页面”的基础结构：

```text
paid-leave-system/
├─ login.html
├─ register.html
├─ index.html
├─ apply.html
├─ confirm.html
├─ complete.html
└─ applications.html
```

本阶段不使用 CSS、不使用 JavaScript、不使用前端框架。页面保持浏览器默认外观，重点是把结构、内容、表单、表格、链接和语义写正确。

七个页面的职责如下：

| 页面 | 文件 | 本阶段重点 |
| --- | --- | --- |
| ログイン | `login.html` | 账号、密码表单和注册链接 |
| アカウント登録 | `register.html` | 注册资料表单，不让学员实现真实保存 |
| ホーム | `index.html` | 员工信息、剩余天数和功能入口 |
| 休暇申請 | `apply.html` | 休假申请表单 |
| 申請内容確認 | `confirm.html` | 固定测试数据的确认画面 |
| 申請完了 | `complete.html` | 固定受付番号和完成提示 |
| 申請一覧 | `applications.html` | 申请状态测试数据表格 |

## 2. 学习方式

请按练习文件中的任务顺序完成：

1. 先建立七个 HTML 文件和不同的页面标题。
2. 完成登录页与注册页的表单。
3. 完成登录后五个业务页面的共通导航。
4. 完成首页、申请输入、确认、完成、一览页面。
5. 最后完成 HTML 自测和日本项目式改修任务。

完成 HTML 阶段后，后续 CSS 课程会继续使用同一个 `paid-leave-system` 项目添加样式；JavaScript 阶段会继续在同一项目中实现动态业务流程。

## 3. 验收重点

提交前至少确认：

- 七个 HTML 文件都能直接用浏览器打开。
- 登录页可以前往注册页，注册页可以返回登录页。
- 登录后的五个业务页面可以通过导航互相访问。
- 表单控件都有明确的 `label`、`name` 和必要提示。
- 登录和注册表单不会用 GET 提交密码。
- 表格用于展示申请一览数据，不用于页面布局。
- 页面没有使用 CSS 或 JavaScript。
- HTML 检查工具没有未处理的结构错误。
