# 元素、属性与嵌套

## 本章目标

完成本章后，你可以：

- 区分标签、元素和属性
- 使用 `属性名="属性值"` 编写属性
- 认识 `id`、`class`、`title`、`lang`、`hidden`
- 正确理解布尔属性
- 排查属性引号、重复属性和嵌套错误

## 1. 标签、元素和属性

观察下面的代码：

```html
<p id="event-time" title="活动开始时间">活动时间：14:00</p>
```

- `<p>` 和 `</p>` 是标签。
- 从开始标签到结束标签的整体是一个元素。
- `id="event-time"` 和 `title="活动开始时间"` 是属性。
- `活动时间：14:00` 是元素内容。

标签说明内容是什么，属性为元素补充名称、状态或其他信息。

## 2. 属性的基本写法

属性通常写在开始标签中：

```html
<标签名 属性名="属性值">内容</标签名>
```

多个属性之间使用空格分隔：

```html
<p id="event-time" class="event-info">活动时间：14:00</p>
```

推荐始终给普通属性值加双引号。这样可以减少空格和特殊字符导致的错误。

## 3. 高频通用属性

通用属性可以用于大多数 HTML 元素，但是否需要使用取决于实际内容。

| 属性 | 可接受的值 | 是否必填/默认值 | 作用 |
| --- | --- | --- | --- |
| `id` | 当前页面中唯一的、不含空格的名称 | 选填；默认没有 | 唯一标识一个元素，也可作为页内跳转目标 |
| `class` | 一个或多个用空格分隔的分类名称 | 选填；默认没有 | 为多个同类元素设置分类名称 |
| `title` | 普通文本 | 选填；默认没有 | 提供补充信息，部分浏览器会在鼠标停留时显示 |
| `lang` | 语言代码，如 `zh-CN`、`ja`、`en` | 选填；通常由 `html` 继承 | 声明元素内容使用的语言 |
| `hidden` | 布尔属性 | 选填；默认不隐藏 | 表示当前内容暂时不应显示 |

### 3.1 `id`：页面内唯一名称

```html
<h1 id="page-title">公司技术交流会</h1>
```

同一个页面中不要重复使用相同 `id`：

```html
<!-- 错误：两个元素使用了相同 id -->
<p id="event-info">活动时间：14:00</p>
<p id="event-info">活动地点：三楼会议室</p>
```

可以改成：

```html
<p id="event-time">活动时间：14:00</p>
<p id="event-place">活动地点：三楼会议室</p>
```

### 3.2 `class`：为同类内容命名

```html
<p class="event-info">活动时间：14:00</p>
<p class="event-info">活动地点：三楼会议室</p>
```

多个元素可以使用相同 `class`。当前只需理解它表示“这些元素属于同一类”。本课程不使用 CSS 或 JavaScript 操作它。

一个元素也可以属于多个分类：

```html
<p class="event-info important">报名截止：2026年9月15日</p>
```

### 3.3 `title`：补充信息

```html
<p title="请提前十分钟入场">活动时间：14:00</p>
```

`title` 只能作为补充信息，不能用它代替页面中本来就应该看见的文字。

### 3.4 `lang`：标记局部语言

整个页面使用中文，但其中有一段日语时，可以写：

```html
<p lang="ja">技術交流会へようこそ。</p>
```

没有语言变化时，不需要给每个元素重复添加 `lang`。

### 3.5 `hidden`：暂时隐藏内容

```html
<p hidden>报名已经结束。</p>
```

浏览器不会正常显示带有 `hidden` 的内容。它不适合存放密码、令牌等秘密信息，因为内容仍然写在 HTML 文件里。

## 4. 布尔属性

`hidden` 属于布尔属性。布尔属性只关心“有没有写”，不根据字符串 `"true"` 或 `"false"` 判断。

下面两种写法都表示隐藏：

```html
<p hidden>报名结束</p>
<p hidden="hidden">报名结束</p>
```

初学阶段推荐较短的第一种写法。

下面的代码仍然表示隐藏：

```html
<p hidden="false">这段内容仍然会被隐藏</p>
```

如果不想隐藏，应删除整个 `hidden` 属性：

```html
<p>这段内容正常显示</p>
```

后续还会遇到 `required`、`checked`、`selected`、`disabled` 等布尔属性，它们遵循相同规则。

## 5. 属性书写规则

### 5.1 属性之间要有空格

正确：

```html
<p id="event-time" class="event-info">活动时间：14:00</p>
```

错误：

```html
<p id="event-time"class="event-info">活动时间：14:00</p>
```

### 5.2 不要重复同名属性

错误：

```html
<p id="time" id="event-time">活动时间：14:00</p>
```

一个开始标签中，同名属性只能出现一次。

### 5.3 引号必须配对

错误：

```html
<p title="请提前入场>活动时间：14:00</p>
```

修正：

```html
<p title="请提前入场">活动时间：14:00</p>
```

### 5.4 属性必须写在开始标签中

错误：

```html
<p> id="event-time" 活动时间：14:00</p>
```

修正：

```html
<p id="event-time">活动时间：14:00</p>
```

## 6. 当前只需简单了解的属性

下面这些也是 HTML 属性，但当前课程不要求使用：

| 属性 | 简单说明 |
| --- | --- |
| `style` | 直接写外观样式；属于 CSS 内容，本课程不使用 |
| `data-*` | 保存自定义数据；通常与 JavaScript 配合，后续再学 |
| `contenteditable` | 让页面内容可以直接编辑；普通内容页面很少需要 |
| `draggable` | 声明元素是否可以拖动；完整拖动行为通常还需要脚本 |
| `accesskey` | 设置快捷键；容易与系统或浏览器快捷键冲突 |

认识名称即可，不要把它们加入当前项目。

## 7. 更新贯穿项目

在 `index.html` 中只修改 `body` 内的内容：

```html
<body>
    <h1 id="page-title">公司技术交流会</h1>
    <p class="event-info" title="请提前十分钟入场">活动时间：2026年9月18日 14:00</p>
    <p class="event-info">活动地点：公司三楼会议室</p>
    <p hidden>报名已经结束。</p>
</body>
```

### 验证

1. 页面显示标题、活动时间和活动地点。
2. “报名已经结束”不显示。
3. 删除 `hidden` 后保存并刷新，“报名已经结束”会显示。
4. 恢复 `hidden`，为后续课程保留当前状态。

## 8. 改修练习

收到以下修改要求：

> 在活动页面增加“报名截止日期”，并把它与时间、地点归为同一类信息。该元素需要一个页面内唯一名称。

请添加：

```html
<p id="registration-deadline" class="event-info">报名截止：2026年9月15日</p>
```

完成后检查：

- `id` 在当前页面中没有重复
- `class` 与其他活动信息一致
- 属性之间有空格
- 属性值的引号完整配对
