# HTML 文档结构

## 本章目标

完成本章后，你可以：

- 写出完整的 HTML 文档骨架
- 解释 `doctype`、`html`、`head`、`body` 的作用
- 正确设置页面语言、字符编码和标签页标题
- 检查标签是否正确闭合和嵌套

## 1. 完整文档骨架

一个基础 HTML 文档如下：

```html
<!doctype html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>公司技术交流会</title>
</head>
<body>
    <h1>公司技术交流会</h1>
    <p>欢迎参加本月的技术交流会。</p>
</body>
</html>
```

## 2. `<!doctype html>`：声明 HTML 文档

`<!doctype html>` 位于文件第一行，用来告诉浏览器：这个文件按照现代 HTML 规则解析。

```html
<!doctype html>
```

它不是普通 HTML 元素，没有结束标签，也不显示在页面中。每个完整 HTML 文件都应保留这一行。

## 3. `<html>`：整个文档的根元素

除了 `doctype` 之外，页面内容都包含在 `<html>` 和 `</html>` 之间。

```html
<html lang="zh-CN">
    <!-- head 和 body 写在这里 -->
</html>
```

### `lang` 属性

`lang` 用来说明页面主要使用哪一种语言。

| 属性 | 可接受的值 | 是否必填/默认值 | 作用 |
| --- | --- | --- | --- |
| `lang` | 语言代码，如 `zh-CN`、`ja`、`en` | 建议填写；省略时浏览器无法从该属性得知主语言 | 声明文档主要语言 |

本课程的中文页面使用：

```html
<html lang="zh-CN">
```

常见值：

- `zh-CN`：简体中文
- `ja`：日语
- `en`：英语

`lang` 不会把页面自动翻译成对应语言，它只是说明内容使用的语言。

## 4. `<head>`：页面信息

`<head>` 保存页面自身的信息。这些信息通常不会作为正文直接显示。

```html
<head>
    <meta charset="UTF-8">
    <title>公司技术交流会</title>
</head>
```

初学阶段先掌握 `meta charset` 和 `title`。

### `<meta charset="UTF-8">`

`meta` 用来提供页面信息。`charset` 属性声明文件采用的字符编码。

| 属性 | 可接受的值 | 是否必填/默认值 | 作用 |
| --- | --- | --- | --- |
| `charset` | 本课程统一使用 `UTF-8` | 完整页面应填写 | 帮助浏览器正确读取中文、日文等字符 |

`meta` 是空元素，不包围正文，所以不写 `</meta>`。

### `<title>`

`title` 设置页面标题。它通常显示在浏览器标签页和收藏记录中。

```html
<title>公司技术交流会</title>
```

每个页面都应有能够说明本页内容的标题。例如：

- 首页：`公司技术交流会`
- 日程页：`活动日程｜公司技术交流会`
- 报名页：`活动报名｜公司技术交流会`

## 5. `<body>`：页面正文

用户要阅读和操作的内容写在 `<body>` 中。

```html
<body>
    <h1>公司技术交流会</h1>
    <p>欢迎参加本月的技术交流会。</p>
</body>
```

标题、段落、链接、图片、列表、表格和表单都属于页面正文。

## 6. 开始标签和结束标签

大多数元素由开始标签、内容和结束标签组成：

```html
<p>欢迎参加活动。</p>
```

- `<p>`：开始标签
- `欢迎参加活动。`：元素内容
- `</p>`：结束标签

有些元素不包围内容，称为空元素：

```html
<meta charset="UTF-8">
```

当前常见空元素还有 `img`、`input`、`br`。遇到这些标签时不要添加不存在的结束标签。

## 7. 正确嵌套

元素放进另一个元素时，必须按顺序关闭。

正确：

```html
<body>
    <p>欢迎参加活动。</p>
</body>
```

错误：

```html
<body>
    <p>欢迎参加活动。
</body>
</p>
```

可以把标签想象成成对的盒子：后打开的盒子要先关闭。

## 8. 缩进

缩进不会直接改变页面内容，但可以清楚地表示父子关系。

推荐：

```html
<body>
    <h1>公司技术交流会</h1>
    <p>欢迎参加本月的技术交流会。</p>
</body>
```

本课程统一使用 4 个空格缩进。

## 9. HTML 注释

注释用于向阅读代码的人说明内容，不显示在正常页面中。

```html
<!-- 页面主标题 -->
<h1>公司技术交流会</h1>
```

注释以 `<!--` 开始，以 `-->` 结束。不要把密码、账号或其他敏感信息写进注释，因为访问者仍然可以查看 HTML 源代码。

## 10. 更新贯穿项目

确认 `index.html` 与下面的完整状态一致：

```html
<!doctype html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>公司技术交流会</title>
</head>
<body>
    <!-- 页面主标题 -->
    <h1>公司技术交流会</h1>
    <p>活动时间：2026年9月18日 14:00</p>
    <p>活动地点：公司三楼会议室</p>
</body>
</html>
```

### 验证

1. 保存文件并刷新浏览器。
2. 页面正文应显示一个标题和两个段落。
3. 浏览器标签页应显示“公司技术交流会”。
4. HTML 注释不应显示在页面中。

## 11. 排错练习

下面的代码有四个问题：

```html
<html>
<head>
    <meta charset="UTF-8">
</head>
<body>
    <h1>公司技术交流会
    <p>欢迎参加活动。</p>
</html>
```

请修正：

1. 补上 `doctype`。
2. 给 `html` 添加 `lang`。
3. 在 `head` 中添加 `title`。
4. 补全 `h1` 和 `body` 的结束标签。

修正后用浏览器重新打开，确认标题和段落正常显示。
