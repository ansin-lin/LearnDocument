# HTML 递进练习自测核对

本章不提供可直接复制的完整参考答案。请先完成[第十四章 HTML 新人综合练习](14_html_project.md)，再根据下面清单核对自己的提交物。

完整任务要求以 [HTML 递进练习：有給休暇申請システム](../training/01_html_task.md) 为准。

## 1. 文件核对

项目目录应包含：

```text
paid-leave-system/
├─ index.html
├─ apply.html
├─ confirm.html
├─ complete.html
└─ applications.html
```

五个页面都应是完整 HTML 文档，包含：

- `<!doctype html>`
- `html`
- `head`
- `meta charset="UTF-8"`
- 有意义的 `title`
- `body`

## 2. 页面迁移核对

请逐项检查：

- 首页可以进入休暇申请页面。
- 首页可以进入申请一览页面。
- 休暇申请页面可以提交到确认页面。
- 确认页面可以进入完成页面。
- 确认页面可以返回休暇申请页面。
- 完成页面可以返回首页或申请一览页面。

HTML 阶段不要求动态传值。确认页可以显示固定测试数据，但必须说明动态传值会在 JavaScript 阶段实现。

## 3. 语义与表单核对

请确认：

- 页面主标题使用 `h1`。
- 页面区域使用合适的语义元素。
- 导航使用链接，不用普通文字假装链接。
- 表单控件具有可关联的 `label`。
- 必填字段使用 HTML 原生属性和文字说明共同提示。
- 申请一览使用表格表达行列数据。
- 不使用表格做页面布局。

## 4. 阶段边界核对

HTML 阶段不能做以下事情：

- 不写 CSS。
- 不写 JavaScript。
- 不伪造真实保存。
- 不声称已经完成动态校验、筛选或取消。

如果页面中需要提示后续功能，应明确写成“JavaScript 阶段实现”。
