# 认识 HTML 并创建第一个网页

## 本章目标

完成本章后，你可以：

- 说明 HTML 在网页中的作用
- 创建一个 `.html` 文件
- 使用浏览器打开并查看网页
- 修改内容并确认浏览器中的变化

## 1. 网页和 HTML

网页是浏览器可以打开并显示的文档。网页中可以包含文字、链接、图片、表格和表单。

HTML 是 HyperText Markup Language 的缩写，中文通常称为“超文本标记语言”。HTML 不是用来计算的编程语言，它使用标签标记内容的职责。

例如：

```html
<h1>公司技术交流会</h1>
<p>欢迎参加本月的技术交流会。</p>
```

`<h1>` 表示一级标题，`<p>` 表示一个段落。浏览器根据标签的含义显示内容。

## 2. 创建项目目录

在自己容易找到的位置创建下面的目录和文件：

```text
html-event-site/
└─ index.html
```

文件名中的 `.html` 是扩展名，表示这是一个 HTML 文档。

注意确认文件不是 `index.html.txt`。如果系统隐藏了扩展名，请先让文件管理器显示文件扩展名。

## 3. 写入第一个完整网页

打开 `index.html`，输入以下完整内容：

```html
<!doctype html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>公司技术交流会</title>
</head>
<body>
    <h1>公司技术交流会</h1>
    <p>欢迎参加本月的技术交流会。</p>
</body>
</html>
```

现在不需要记住所有标签。下一章会逐一解释文档结构。

## 4. 用浏览器查看

1. 保存 `index.html`。
2. 在文件管理器中双击该文件。
3. 浏览器会显示“公司技术交流会”和一段说明。
4. 浏览器标签页上会显示“公司技术交流会”。

### 修改并再次确认

把段落改成：

```html
<p>活动时间：2026年9月18日 14:00</p>
```

保存文件，然后刷新浏览器。页面内容也应随之改变。

这一步建立了最基本的工作循环：

```text
修改 HTML → 保存文件 → 刷新浏览器 → 检查结果
```

## 5. 浏览器读取了什么

浏览器打开 `index.html` 后，会读取其中的标签和文字，并把它们转换成可以查看的页面。

HTML 负责说明内容的结构。例如：

- 这是网页标题
- 这是一个段落
- 这是一个链接
- 这是一个表单输入框

字体、颜色和复杂布局不属于本课程范围，后续 CSS 课程会负责页面外观。

## 6. 常见失败

| 现象 | 可能原因 | 检查方法 | 修正方式 |
| --- | --- | --- | --- |
| 双击后用记事本打开 | 文件扩展名不是 `.html`，或默认应用设置不正确 | 查看完整文件名 | 改为 `index.html`，或选择浏览器打开 |
| 修改后页面没有变化 | 文件没有保存，或浏览器没有刷新 | 查看编辑器保存状态 | 保存文件并刷新页面 |
| 页面出现乱码 | 文件保存编码不一致 | 查看编辑器编码 | 使用 UTF-8 保存 |
| 页面一片空白 | 内容没有写在 `body` 中，或文件内容未保存 | 重新打开文件检查 | 对照完整示例修正 |

## 7. 本章练习

在 `index.html` 中完成以下修改：

1. 把一级标题改为“新人技术分享会”。
2. 增加两个段落，分别写活动日期和活动地点。
3. 保存并刷新浏览器。

完成后，页面应显示一个标题和三个段落。

## 8. 本章检查

- 文件名是 `index.html`
- 文件可以用浏览器打开
- 修改并保存后，刷新浏览器可以看到变化
- 页面没有乱码
