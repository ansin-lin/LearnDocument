# 列表标签

## 本章目标

完成本章后，你可以：

- 根据内容选择无序列表、有序列表或描述列表
- 正确嵌套 `ul`、`ol`、`li`、`dl`、`dt`、`dd`
- 使用 `start`、`reversed` 和 `value` 调整有序列表编号
- 用列表整理活动主题和参加说明

## 1. 为什么使用列表

当多个内容属于同一组时，应使用列表，而不是连续写多个段落或手动输入项目符号。

HTML 有三种常用列表：

| 内容特点 | 使用标签 | 示例 |
| --- | --- | --- |
| 项目没有先后顺序 | `ul` | 注意事项、功能清单 |
| 项目有步骤或排名 | `ol` | 操作步骤、活动流程 |
| 名称与解释成对出现 | `dl` | 术语解释、问答摘要 |

列表表达的是内容关系，不负责页面横向或纵向布局。

## 2. 无序列表 `ul`

```html
<ul>
    <li>项目开发流程分享</li>
    <li>代码审查经验交流</li>
    <li>新人提问时间</li>
</ul>
```

`ul` 的直接子元素应是 `li`。文字和其他内容放在 `li` 中。

错误：

```html
<ul>
    活动主题
    <li>项目开发流程分享</li>
</ul>
```

修正：

```html
<h2>活动主题</h2>
<ul>
    <li>项目开发流程分享</li>
</ul>
```

## 3. 有序列表 `ol`

步骤有明确顺序时使用 `ol`：

```html
<ol>
    <li>打开活动报名页</li>
    <li>填写报名信息</li>
    <li>确认并提交</li>
</ol>
```

浏览器会为列表项显示顺序编号。

## 4. 有序列表的常用属性

### 4.1 `ol` 属性

| 属性 | 可接受的值 | 是否必填/默认值 | 作用 |
| --- | --- | --- | --- |
| `start` | 整数 | 选填；默认从 1 开始 | 设置第一项的编号 |
| `reversed` | 布尔属性 | 选填；默认正序 | 让编号倒序显示 |
| `type` | `1`、`a`、`A`、`i`、`I` | 选填；默认 `1` | 设置编号类型 |

从第 3 项开始：

```html
<ol start="3">
    <li>确认报名内容</li>
    <li>提交报名</li>
</ol>
```

倒序编号：

```html
<ol reversed>
    <li>报名即将截止</li>
    <li>请尽快确认</li>
    <li>完成报名</li>
</ol>
```

`type` 会改变编号形式，但不会改变内容的顺序含义：

```html
<ol type="A">
    <li>会议室 A</li>
    <li>会议室 B</li>
</ol>
```

普通步骤使用默认数字即可。

### 4.2 `li` 的 `value`

| 属性 | 可接受的值 | 是否必填/默认值 | 作用 |
| --- | --- | --- | --- |
| `value` | 整数 | 选填；默认延续上一项编号 | 单独设置当前有序列表项的编号 |

```html
<ol>
    <li>第一项</li>
    <li value="5">第五项</li>
    <li>第六项</li>
</ol>
```

`value` 只在确实需要中断编号时使用。普通流程不要人为跳号。

## 5. 列表嵌套

子列表必须放在某个 `li` 内部：

```html
<ul>
    <li>
        开发基础
        <ul>
            <li>HTML</li>
            <li>Git</li>
        </ul>
    </li>
    <li>项目沟通</li>
</ul>
```

不要把子 `ul` 与 `li` 并列放置。

## 6. 描述列表 `dl`

描述列表适合“名称—说明”结构：

```html
<dl>
    <dt>活动对象</dt>
    <dd>入职一年以内的开发人员</dd>

    <dt>活动地点</dt>
    <dd>公司三楼会议室</dd>
</dl>
```

- `dl`：整个描述列表
- `dt`：名称或术语
- `dd`：对名称的说明

同一个 `dt` 可以对应多个 `dd`，但普通场景保持一组一组书写更容易阅读。

## 7. 更新贯穿项目

在 `index.html` 的“活动介绍”之后加入：

```html
<h2>分享主题</h2>
<ul>
    <li>项目开发流程</li>
    <li>代码审查中的常见指摘</li>
    <li>新人如何整理自测结果</li>
</ul>

<h2>报名步骤</h2>
<ol>
    <li>查看活动日程</li>
    <li>打开报名页面</li>
    <li>填写并提交报名信息</li>
</ol>

<h2>基本信息</h2>
<dl>
    <dt>活动对象</dt>
    <dd>入职一年以内的开发人员</dd>

    <dt>活动费用</dt>
    <dd>免费</dd>
</dl>
```

### 验证

- 三个分享主题显示为同一组无序列表
- 报名步骤自动显示 1、2、3
- 活动对象和活动费用分别与说明对应
- `ul` 和 `ol` 的直接子元素都是 `li`

## 8. 排错练习

修正下面的结构：

```html
<ol>
    第一步
    <li>打开报名页</li>
    <ul>
        <li>确认活动日期</li>
    </ul>
</ol>
```

要求：

- “第一步”不能直接放在 `ol` 中
- 子列表必须放进对应 `li`
- 如果只有一个步骤，不需要人为写“第一步”
