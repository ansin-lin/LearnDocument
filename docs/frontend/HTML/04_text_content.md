# 文本内容标签

## 本章目标

完成本章后，你可以：

- 使用标题和段落组织文章
- 使用 `strong` 和 `em` 表达重要性与强调
- 正确使用换行和分隔线
- 在页面中显示小于号、和号等特殊字符
- 把活动通知整理成容易阅读的 HTML 文档

## 1. 标题：`h1` 到 `h6`

HTML 提供六级标题：

```html
<h1>公司技术交流会</h1>
<h2>活动介绍</h2>
<h3>分享主题</h3>
```

`h1` 表示页面的主标题，`h2` 表示主标题下的大章节，`h3` 表示 `h2` 下的子章节。标题级别体现内容层级，不是为了选择字体大小。

推荐保持连续的标题层级：

```html
<h1>公司技术交流会</h1>
<h2>活动介绍</h2>
<h2>活动安排</h2>
<h3>第一场分享</h3>
<h3>第二场分享</h3>
```

不要因为想让文字变小就从 `h1` 直接跳到 `h4`。

## 2. 段落：`p`

一个完整意思通常写成一个段落：

```html
<p>本次活动面向刚加入项目的开发人员。</p>
<p>参加者可以了解项目开发流程和常见沟通方式。</p>
```

不要用多个 `br` 模拟段落。不同意思应使用不同的 `p`。

## 3. 换行：`br`

`br` 用于内容本身需要换行的场景，例如地址：

```html
<p>
    东京都千代田区示例町1-2-3<br>
    示例大厦3楼
</p>
```

`br` 是空元素，不写 `</br>`。

普通文章会根据窗口宽度自动换行，不需要在每行末尾添加 `br`。

## 4. 主题分隔：`hr`

`hr` 表示内容主题发生分隔：

```html
<p>以上是活动说明。</p>
<hr>
<p>以下是报名注意事项。</p>
```

`hr` 不是单纯为了画一条线。只有内容确实发生主题转换时才使用。

## 5. 重要和强调

### 5.1 `strong`：重要内容

```html
<p><strong>报名截止日期：2026年9月15日</strong></p>
```

`strong` 表示内容具有较高的重要性。

### 5.2 `em`：语气强调

```html
<p>请务必在活动开始前 <em>十分钟</em> 入场。</p>
```

`em` 表示阅读时需要强调的部分。

不要只因为浏览器默认显示粗体或斜体就选择这两个标签。应根据内容含义选择。

## 6. 修改记录：`del` 和 `ins`

`del` 表示已经删除的内容，`ins` 表示新增的内容：

```html
<p>活动地点：<del>二楼会议室</del> <ins>三楼会议室</ins></p>
```

这适合展示通知发生了什么修改。如果只需要显示最新结果，直接写最新内容即可。

## 7. 代码和键盘输入

技术文档中可以使用：

```html
<p>请打开 <code>index.html</code> 文件。</p>
<p>保存后按 <kbd>Ctrl</kbd> + <kbd>S</kbd>。</p>
```

- `code`：文件名、代码或计算机指令
- `kbd`：用户需要按下的键

## 8. 上标、下标和小字

这些标签只需会看懂：

```html
<p>水的化学式是 H<sub>2</sub>O。</p>
<p>面积单位示例：m<sup>2</sup>。</p>
<p><small>活动安排可能根据现场情况调整。</small></p>
```

- `sub`：下标
- `sup`：上标
- `small`：附注、版权等次要文字

不要为了单纯改变字号而滥用 `small`。

## 9. 特殊字符

HTML 使用 `<`、`>` 和 `&` 表示语法。需要把它们作为普通文字显示时，可以使用字符引用。

| 要显示的字符 | HTML 写法 | 常见用途 |
| --- | --- | --- |
| `<` | `&lt;` | 显示标签左尖括号 |
| `>` | `&gt;` | 显示标签右尖括号 |
| `&` | `&amp;` | 显示和号 |
| 不换行空格 | `&nbsp;` | 少量确实不能换行的空格 |
| `©` | `&copy;` | 版权符号 |

示例：

```html
<p>段落标签写作 &lt;p&gt;内容&lt;/p&gt;。</p>
<p>研发部 &amp; 运营部共同举办。</p>
```

不要连续写很多 `&nbsp;` 来排列内容。列表、表格等结构应使用对应标签。

## 10. 更新贯穿项目

将 `index.html` 的 `body` 替换为：

```html
<body>
    <h1 id="page-title">公司技术交流会</h1>

    <h2>活动介绍</h2>
    <p>本次活动面向刚加入项目的开发人员。</p>
    <p>参加者可以了解项目开发流程和常见沟通方式。</p>

    <h2>活动信息</h2>
    <p class="event-info">活动时间：2026年9月18日 14:00</p>
    <p class="event-info">
        活动地点：东京都千代田区示例町1-2-3<br>
        示例大厦3楼
    </p>
    <p id="registration-deadline" class="event-info">
        <strong>报名截止：2026年9月15日</strong>
    </p>

    <hr>

    <h2>参加提示</h2>
    <p>请在活动开始前 <em>十分钟</em> 入场。</p>
    <p><small>活动安排可能根据现场情况调整。</small></p>
</body>
```

### 验证

- 页面只有一个主标题
- “活动介绍”“活动信息”“参加提示”是同级标题
- 地址在同一段落中换行
- 报名截止信息被标记为重要内容
- 注释性文字仍然可以阅读

## 11. 改修练习

活动开始时间由 14:00 改为 14:30。请使用 `del` 和 `ins` 显示这次修改：

```html
<p class="event-info">活动时间：2026年9月18日 <del>14:00</del> <ins>14:30</ins></p>
```

完成后检查标签是否成对闭合。
