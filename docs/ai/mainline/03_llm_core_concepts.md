# 第 3 章 LLM 核心概念

> 本章成果：能够区分上下文窗口、知识截止、会话历史、记忆和 RAG，理解常见生成参数，并使用证据核对法识别幻觉与时效风险。

## 1. 五种“模型知道的信息”

模型训练后，部分语言和事实模式存在参数中，但不是可逐条查询来源的数据库。知识可能不完整、过时或冲突。

Knowledge Cutoff 描述训练知识大致覆盖的时间边界。它不保证截止日前全部知道，也不保证之后完全不知道。产品可能另外提供搜索和工具，因此要确认新信息来自模型参数、当前上下文还是外部工具。

当前上下文包括系统指令、用户输入、会话消息、上传内容和工具结果。文件存在电脑里不代表模型已经读取。应用记忆则是产品保存偏好或摘要并在以后重新提供，不是模型天然永久记住所有聊天。

RAG 会在请求时检索文档片段，工具可以查询数据库或业务 API。它们能提供外部事实，但检索可能不相关、工具可能失败，权限仍由应用控制。

| 概念 | 主要作用 | 常见误解 |
| --- | --- | --- |
| 知识截止 | 描述训练知识的时间边界 | 截止日前全部正确 |
| 上下文窗口 | 限制一次处理的总内容 | 窗口越大一定越好 |
| 会话历史 | 维持当前对话连续性 | 模型永久记住全部聊天 |
| Memory | 应用保存并再次提供的信息 | 记忆一定真实且不过期 |
| RAG | 检索外部资料 | 接入后不会幻觉 |

## 2. Context Window 与输出上限

上下文窗口通常容纳系统指令、输入、历史、工具结果和输出预算。它按 Token 计算，不按文件数量。超出时可能报错、截断或压缩，具体取决于产品和 API。

`max_output_tokens` 一类参数限制最大输出，并不保证用满。上限过小可能使回答或 JSON 中断；过大可能增加延迟和费用风险。应用应检查响应完成状态。

## 3. Temperature 与采样

模型得到候选 Token 概率后按支持的采样配置选择输出。Temperature 通常调整分布的集中程度：较低设置常使输出更集中，较高设置可能增加多样性。

Temperature 不是准确率或创造力百分比，不能修复缺数据、错误 Prompt 和权限问题。有些模型限制某些参数，应以当前文档和实验为准。结构化提取依靠 Schema、业务校验和评估集，而不是只降低 Temperature。

## 4. 什么是幻觉

常见幻觉包括：虚构接口；给出无来源规则；把旧版当最新版；引用真实文档但文档不支持结论；工具失败后声称操作成功；把推测写成事实。

原因可能是训练知识有限、上下文缺失或冲突、问题含错误前提、检索未命中、输出截断，或应用没有校验结果。

## 5. 四层核对法

1. **格式层**：输出是否完整，JSON 或表格能否解析。
2. **事实层**：声明能否在资料、官方文档或业务数据找到依据。
3. **业务层**：字段、权限、金额和状态流转是否符合规则。
4. **执行层**：声称运行、修改或发送的动作是否有真实结果。

| 模型声明 | 来源 | 核对动作 | 结论与处理 |
| --- | --- | --- | --- |
| SD-001 为 HIGH | 当前接口响应 | 查询隔离测试库 | 已确认 |
| HIGH 必须一小时处理 | 未提供 SLA | 查当前 SLA 文档 | 待确认，不进入结论 |
| 已更新为 CLOSED | 只有模型文本 | 查版本和审计日志 | 未执行，禁止报告成功 |

## 6. 对照实验

用同一份工单执行三组请求：只给相关工单；加入十段无关日志；再加入冲突的旧规格。固定其他条件，记录遗漏、无依据声明、Token 和响应时间。再用两个采样设置各执行多次摘要，比较措辞和事实错误。

如果调低 Temperature 后事实错误仍存在，说明它不能保证真实性；如果加入无关内容后效果下降，说明上下文容量和上下文质量是不同问题。

## 7. 练习与参考答案

模型回答：“根据公司 2024 版手册，SD-001 应自动关闭”，但当前只提供 2023 版手册，也没有工具调用记录。

参考核对：格式可能正确；“2024 版”没有依据；自动关闭需要业务规则和权限确认；没有执行证据，不能说状态已修改。合格回答应说明资料不足、请求当前手册，并在任何写入前经过授权和人工确认。

## 8. 新人核对卡

上下文窗口是一次请求可处理信息的容量，不是永久记忆；Temperature 影响采样随机性，不是正确率旋钮；知识截止描述训练知识范围，不代表模型知道截止日前每件事；幻觉是无依据却像真的输出，不只包括“编故事”，也包括不存在的 API、错误数字和伪造引用。

核对顺序固定为：先看格式，再查资料依据，再用程序或权威来源验证业务事实，最后验证动作是否真的执行。任何一步失败，都不能因为语气自信而放行。
