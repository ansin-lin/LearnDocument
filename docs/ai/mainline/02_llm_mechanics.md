# 第 2 章 LLM 工作原理

> 本章成果：能够用具体输入解释 Token、向量表示、Transformer、Attention 和逐 Token 生成，并说明 LLM 为什么能写出自然语言又可能产生错误事实。

## 1. 一次生成经历什么

假设用户输入：“请把这张工单整理成一句摘要”。模型不会像人一样先完整写好答案，而是大致经历：文本切分为 Token；Token 转为数值表示并结合位置；多层 Transformer 计算上下文关系；得到下一个 Token 的概率；选择一个 Token；加入上下文后继续预测。

```text
输入文本 → Token 化 → 向量与位置 → Transformer
        → 下一个 Token 概率 → 选择并追加 → 重复直到停止
```

这是学习用的简化图，真实模型包含更多细节，不能把每个方框理解成简单独立函数。

## 2. Token：模型处理文本的基本单位

Token 可以是一个字、词的一部分、标点或其他片段，具体切分由模型的 tokenizer 决定。“工单编号 SD-001”可能被切成多个 Token，但不能脱离具体模型声称固定数量。

Token 数量影响上下文容量、延迟和费用。字符数、单词数和 Token 数不是固定比例；中英混合、代码和特殊符号也会改变切分。实际应用读取 tokenizer 或 API usage，不使用“一个汉字等于一个 Token”的公式。

## 3. 向量表示：把符号变成数字

Token 本身只是编号，模型把它映射为一组可学习的数字，并结合位置和上下文逐层更新。这样，“苹果”在水果语境和公司语境中的内部表示会受到周围文字影响。

内部 Token 表示与后续用于检索的 Embedding 有联系，但用途不能简单等同。检索 Embedding 通常把一段文本表示成可比较的向量；模型内部会维护每个位置的上下文化表示。

## 4. Transformer 与 Attention

Transformer 是现代 LLM 常用的神经网络架构。Attention 让某个位置在计算时根据当前内容关注其他位置。例如处理“用户说重置后仍无法登录，因此建议检查账号状态”时，后面的判断会利用前文。

Attention 不是事实数据库，也不是模型展示给人的可验证思考过程。它是计算信息关系的机制，模型仍可能组合出语言合理但材料中不存在的内容。

## 5. 逐 Token 生成

当前输出若是“该工单可能属于”，模型会为“账号”“报表”“权限”等候选计算概率。选择“账号”后，新上下文变成“该工单可能属于账号”，再预测后续 Token，多次选择形成完整回答。

经过大规模训练，模型参数中形成了语言、代码和任务模式，所以它能摘要、分类和生成代码。但这种生成机制也意味着：措辞自然不等于事实有来源。

## 6. 训练、参数与推理

训练阶段用大量样例调整参数，使合适的后续 Token 获得更高概率。推理阶段固定参数，接收当前输入并生成结果。Prompt 通常不会把信息永久写入模型；下次能否使用取决于应用是否再次提供历史、记忆或外部资料。

## 7. 原理怎样影响使用

| 原理 | 实际影响 | 应对方式 |
| --- | --- | --- |
| 输入输出占用 Token | 内容过长会增费或超限 | 提供最小上下文并限制输出 |
| 逐 Token 生成 | 结果可能中断或 JSON 不完整 | 检查状态并执行 Schema 校验 |
| 根据模式生成 | 可能产生合理但错误的事实 | 要求证据并连接权威数据 |
| 结果受上下文影响 | 无关或冲突资料会干扰 | 标注来源、版本和优先级 |
| 不自动访问业务系统 | 不知道实时工单状态 | 使用授权工具或 API |

## 8. 可检查实验

对“SD-001 现在是什么状态？”依次执行：不提供数据；提供 `SD-001=OPEN`；同时提供旧文档 `OPEN` 和新接口结果 `CLOSED`。要求模型列出依据和无法确认项。

记录输入事实、模型声明、声明依据、越过材料的内容和改进方式。正确观察应是：无数据时不能确认；单一可信数据时按数据回答；资料冲突时指出冲突并确认权威来源。

## 9. 自测

判断：“生成前已经保存完整答案”“Attention 等于数据库检索”“调用 API 会继续训练公共模型”“Token 可永远按字符数估算”。四句话都不准确；分别用逐 Token 生成、Attention 边界、训练/推理和 tokenizer 差异修正。

## 10. 新人核对卡

`Token` 是模型处理与计费常用的文本单位，不等于汉字或单词；`Embedding` 是数值表示，不是保存原文的数据库；`Attention` 计算当前输入中哪些部分相互相关，不会自动访问公司系统；`Transformer` 是模型结构，不是一个可以单独调用的业务功能。

如果学员能解释为什么相同开头可能生成不同结尾、为什么长输入影响成本和效果、为什么模型不知道数据库实时状态，就已经掌握了后续工程实践真正需要的原理。
