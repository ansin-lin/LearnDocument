# HTML 学完后的综合练习

## 任务名称

使用纯 HTML 制作“Company WorkHub 任务管理”四个业务页面。

## 开始条件

- 已完成 HTML 课程。
- 已阅读[统一练习规格](00_practice_spec.md)。
- 工作目录为 `workhub-task-practice/frontend/`。
- 本阶段没有 CSS 和 JavaScript，页面可以朴素，但结构必须完整。

## 要完成的页面

1. `tasks.html`：任务列表和查询条件。
2. `task-create.html`：任务新建表单。
3. `task-detail.html`：任务详情和状态操作区域。
4. `task-edit.html`：任务编辑表单。

## 具体要求

### 公共结构

- 四页均为完整 HTML5 文档，使用 UTF-8、`zh-CN`、viewport 和有业务含义的 title。
- 使用 header、nav、main、section、footer 表达页面职责。
- 公共导航包含“任务列表”和“新建任务”，从任一页面都可以返回列表。
- 每页只有一个 h1，后续标题层级连续。
- 页面跳转使用 a，执行操作使用 button，不使用可点击 div。

### 任务列表页

- 查询表单包含关键字、项目、负责人、状态以及查询/重置按钮，查询方法使用 GET。
- 使用表格显示三条固定任务，列为任务编号、标题、项目、负责人、优先级、状态、期限和操作。
- 表格必须包含 caption、thead、tbody 和 `scope="col"` 表头。
- 任务编号链接到 `task-detail.html?id=任务ID`。
- 预留加载中、空数据和错误反馈区域，初始使用 hidden 隐藏。

### 新建和编辑页

- 表单字段为项目、标题、说明、负责人、优先级、开始日和期限。
- 每个控件都有唯一 id、稳定 name 和正确关联的 label。
- 项目、标题、负责人、优先级、开始日、期限必填。
- 标题最多 100 字，说明最多 1000 字，日期使用 `type="date"`。
- option 的 value 使用统一规格中的 id 或枚举 code，不能使用中文显示文字。
- 编辑页通过 URL 中的 id 确定任务；提供保存与取消操作。

### 详情页

- 显示任务编号、标题、说明、项目、负责人、优先级、状态、开始日和期限。
- 提供编辑链接和状态操作区域；当前阶段按钮不需要真正改变数据。
- 为不存在任务和加载失败预留反馈区域。

## 限制

- 不写 CSS、JavaScript、后端代码。
- 不用表格进行页面布局。
- 不使用本机绝对路径。
- HTML 校验属性只是前端提示，不能描述成最终业务校验。

## 验收方法

1. 直接打开四个页面，确认中文和浏览器标题正确。
2. 从任一页面出发，最多两次点击能到达其他任一页面。
3. 关闭样式后检查表格、表单和标题结构仍能理解。
4. 点击每个 label，确认焦点进入对应控件。
5. 只使用键盘 Tab、Enter 完成页面导航和表单操作。
6. 检查重复 id、失效链接、错误嵌套和缺失 label。
7. 尝试空标题和超过长度的标题，确认浏览器基础校验生效。

## 提交物

- 四个 HTML 文件。
- 列表页和新建页截图。
- `evidence/html-check.md`，记录结构、链接、表单和键盘检查结果。

完成标准：即使没有 CSS 和 JavaScript，其他人也能看懂四页职责、查询任务、填写表单并完成页面跳转。
