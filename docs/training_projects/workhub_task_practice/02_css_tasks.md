# CSS 学完后的综合练习

## 任务名称

为 HTML 阶段完成的四个任务管理页面制作统一、响应式且可操作的界面。

## 开始条件

- HTML 综合练习已经通过验收。
- 四个页面的字段和语义结构不再随意改变。
- 新建 `frontend/css/task.css`，四页共用这一份样式表。

## 具体要求

### 基础与组织

- 设置全局 `box-sizing`、字体、行高、页面背景和主容器最大宽度。
- 在 `:root` 定义主色、文字色、边框色、成功色、错误色、间距和圆角变量。
- 样式按基础、布局、组件、状态、响应式顺序组织。
- 类名表达业务职责，例如 `.task-table`，不使用 `.red-text` 这类视觉名称。
- 不使用 `!important` 解决普通层叠问题，不堆叠高权重选择器。

### 页面布局

- 使用 Flexbox 完成页头导航、查询操作区和按钮组。
- 使用 Grid 完成详情字段和编辑表单的二维排列。
- 表格只负责表格数据；在窄屏中由专用容器横向滚动。
- 长标题、长说明和长项目名不能遮挡其他内容或撑破容器。

### 组件与状态

- 统一输入框、下拉框、文本域、主要按钮和次要按钮样式。
- 为 TODO、IN_PROGRESS、DONE 制作状态徽标，并保留状态文字。
- 提供加载中、空数据、成功、失败、字段错误和禁用状态样式。
- 为链接、按钮和表单控件提供清楚的 hover、focus-visible、disabled 状态。
- 错误和状态不能只靠颜色表达。

### 响应式和可用性

- 宽屏表单可以两列显示，说明和错误摘要跨整行。
- 768px 以下改为单列，导航和按钮允许换行。
- 360px 宽度下无需缩放即可完成查询和新建。
- 页面缩放到 200% 时主要内容和操作仍可到达。
- 非必要过渡在 `prefers-reduced-motion: reduce` 下关闭。

## 限制

- 不使用 Bootstrap、Tailwind 或其他 UI 框架。
- 不用固定高度截断业务内容。
- 不为视觉效果删除 label、表头、焦点或状态文字。
- 不用大量魔法数字把元素推到指定位置。

## 验收方法

1. 在 1280px、768px、360px 三种宽度查看四页。
2. 将标题改为 100 字、说明改为长文本，确认没有重叠和页面级横向滚动。
3. 仅使用键盘操作，确认焦点始终可见。
4. 手动显示加载、空数据、成功和失败区域，确认层级正确且不永久遮挡操作。
5. 暂时修改主色变量，确认主要按钮和链接同步变化。
6. 禁用一个按钮，确认外观和行为都与可用按钮不同。
7. 使用开发者工具检查最终生效规则，确认没有无意义覆盖。

## 提交物

- `frontend/css/task.css`。
- 更新后的四个 HTML 文件。
- 桌面列表页、360px 编辑页、键盘焦点状态截图。
- `evidence/css-check.md`，记录三种宽度、长文本和键盘检查结果。

完成标准：四个页面在桌面和窄屏上都能清楚阅读和操作，样式结构可维护，并保留 HTML 阶段的语义和可访问性。
