# JavaScript 学完后的综合练习

## 任务名称

使用原生 JavaScript 将静态任务页面改造成可运行的前端任务管理功能。

## 开始条件

- HTML、CSS 综合练习已经通过验收。
- 已阅读统一字段、状态迁移和初始数据。
- 后端可以尚未完成，本阶段先使用 localStorage 模拟持久化。
- 使用本地 Web 服务器打开页面，不使用 `file://` 运行 ES 模块。

## 要完成的功能

### 数据和模块

- 使用三条固定初始任务，字段与[统一练习规格](00_practice_spec.md)一致。
- 按 `config / repository / service / validation / ui / pages` 组织 ES 模块。
- 页面只能通过 repository 接口访问数据，不能在渲染函数中直接读写 localStorage。
- repository 提供 `searchTasks`、`getTask`、`createTask`、`updateTask`、`updateTaskStatus`。
- 状态和优先级 code 统一转换成显示文字，未知值显示“未知”。

### 列表和查询

- 页面打开时读取并显示任务，排序为 updatedAt 降序、id 降序。
- 支持关键字、项目、负责人和状态组合查询；关键字匹配任务编号和标题。
- 查询结果数量与表格同步更新；无结果时显示空数据状态。
- 使用安全 DOM API 和 textContent 渲染，不能把业务文字直接拼进 innerHTML。

### 新建、详情和编辑

- 新建成功后生成不重复的任务编号，初始状态为 TODO，并跳到详情页。
- 详情页根据 URL 中的 id 读取数据；id 无效或任务不存在时显示错误。
- 编辑页回显已有值，保存成功后重新显示最新内容。
- 校验必填、标题/说明长度和期限不早于开始日；失败时聚焦第一个错误字段。
- 数据刷新后仍保留；只允许清理本练习使用的 storage key。

### 状态和异常

- 状态按钮只显示当前状态允许的下一步，但 repository 仍要再次验证状态迁移。
- 合法状态变更成功；TODO -> DONE 必须失败。
- 异步操作期间显示 loading、禁用重复提交，并在 finally 恢复。
- 模拟数据损坏、保存失败和不存在任务；页面不能白屏，Console 保留可定位信息。

### 为联调预留

- 新建 `apiTaskRepository`，实现与本地仓库相同的方法签名。
- 使用 fetch、URLSearchParams、JSON 请求体和统一错误结构。
- 非 2xx 响应抛出包含业务 code 的错误；使用 AbortController 设置 10 秒超时。
- 配置只允许 `local` 或 `api`，切换数据源时页面代码不修改。

## 限制

- 不使用 jQuery、Vue、React 或现成 CRUD 库。
- 不使用行内事件属性。
- 不在浏览器代码中保存账号、密码、令牌或其他秘密。
- 前端隐藏按钮和校验不能描述成后端权限或最终业务保护。

## 验收用例

1. 初次打开显示三条任务，三种状态各一条。
2. 完成单条件、组合条件、重置和无结果查询。
3. 新建任务后跳到详情，刷新和返回列表后仍存在。
4. 编辑任务后内容更新，其他未编辑字段保持不变。
5. TODO -> IN_PROGRESS 成功，TODO -> DONE 失败且原数据不变。
6. 输入空标题、101 字标题、1001 字说明和逆序日期，均不能保存。
7. 把标题改成 `<img src=x onerror=alert(1)>`，页面只显示文字。
8. 快速双击提交，只产生一条数据。
9. 手动破坏 localStorage JSON，页面显示错误并可恢复三条初始数据。
10. 切换到 api 数据源，能在 Network 中看到符合统一规格的请求；后端未启动时显示网络错误并结束 loading。

## 提交物

- 更新后的四个页面和全部 JavaScript 模块。
- `evidence/javascript-check.md`，记录十个用例的结果。
- 新建、组合查询、非法状态变更、数据损坏恢复四张截图。

完成标准：在 local 数据源下，列表、查询、新建、详情、编辑和状态变更形成完整闭环；切换 API 数据源不需要重写页面业务代码。
