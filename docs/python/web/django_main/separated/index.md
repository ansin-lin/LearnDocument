# Django 前后端分离开发路线

本阶段承接第1–18章的员工管理系统。Model、数据库、权限与业务规则继续复用，响应从 HTML 扩展为 JSON API，独立前端通过 HTTP 契约调用。

## 学习前提

- 已完成服务端渲染主线，能追踪 URL → View → Model/Template。
- 会使用 ORM、认证权限、文件、日志和 Django TestCase。
- 具备 HTML、JavaScript 异步请求、HTTP 与 Git 基础；相关完整原理在站内专项课程学习。

## 章节成果

| 阶段 | 章节 | 可交付成果 |
|---|---:|---|
| API基础 | 19–21 | REST 契约、Serializer、ViewSet/Router CRUD |
| 安全与联调 | 22–24 | JWT、后端权限、安全文件 API、Fetch/CORS |
| 企业列表与质量 | 25–27 | 过滤分页、OpenAPI、API测试、日志与配置 |
| 部署与现场 | 28–29 | 发布/回滚手顺、一次完整 SES API 改修 |

## 学习方法

每章先确认开始状态和接口契约，再修改同一个员工系统；使用 HTTP 客户端和浏览器 Network 观察真实请求；同时验证响应、数据库、权限和日志；保留失败证据并说明原因。不要跳过19章直接复制 ViewSet，否则容易会写代码却看不懂 HTTP 和错误状态。

## 完成后的能力边界

学完后应能在指导与 Review 下进入一体式或分离式 Django 项目，定位常见调用链、完成小型 CRUD/筛选/权限改修并给出测试和交接证据。对于大型架构、复杂异步系统、云平台、安全专项和高并发优化，仍需结合项目继续学习。
