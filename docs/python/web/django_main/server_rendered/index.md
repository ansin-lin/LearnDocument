# Django 服务端渲染学习路线

这部分面向第一次学习 Web 框架的学员。你会持续完善同一个“员工管理系统”，而不是学完孤立知识点后再重新拼项目。

## 学习前提

开始前应能运行简单 Python 程序，理解变量、条件、循环、函数、列表和字典，并掌握 HTML 表单、HTTP 与 Git 的最基础用法。不熟悉时可先学习本课程对应基础章节。

## 课程基线

- Python 3.12 或更高版本
- Django 5.2 LTS，依赖范围 `Django>=5.2,<5.3`
- 开发阶段使用 SQLite
- 示例配置包为 `company_portal`，业务 App 为 `employees`

## 四个学习阶段

| 阶段 | 章节 | 最终成果 |
|---|---:|---|
| 页面与请求 | 01–05 | 显示带 CSS 的静态员工列表 |
| 数据与 CRUD | 06–11 | 完成数据库列表、新增、编辑、逻辑删除、搜索和分页 |
| 安全与质量 | 12–16 | 完成登录、权限、文件安全、日志和自动测试 |
| 交付与现场 | 17–18 | 项目可重新搭建，并完成一次 SES 改修闭环 |

## 每章怎么学

1. 先阅读“本章成果”，确认这次要让系统增加什么能力。
2. 在上一章可运行状态上修改，不跳章复制最终答案。
3. 每完成一个小步骤就启动或运行检查，观察请求、页面和数据库变化。
4. 完成本章必测场景与检查表，再进入下一章。
5. 把错误现象、原因和修复方法记入自己的调查笔记。

代码能运行只是起点。现场更重视你能否读懂规格、说明影响、保护数据、留下测试证据，并把成果交给下一位开发者继续维护。

完成练习后可使用[最终参考项目](reference_project.md)核对组合状态，使用[章节练习参考答案](practice_answers.md)自检，并在具体改修任务中查阅[SES现场日语](ses_japanese.md)。

完成第18章后继续进入[前后端分离开发路线](../separated/index.md)。第二阶段复用同一员工业务和数据库，加入 REST/DRF、JWT、文件 API、前端联调、OpenAPI、部署与 SES API 改修。
