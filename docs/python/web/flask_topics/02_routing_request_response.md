# 第2章 Flask 路由与请求响应

> 项目增量：创建员工列表、详情和新增接口，理解 Flask 如何读取路径、查询、请求头和 JSON 请求体。

## 一、主要内容

1. `@app.route` 与 HTTP 方法
2. 动态路径和类型转换器
3. `request.args`、`request.headers` 和 `request.get_json()`
4. `jsonify()` 与响应对象
5. 状态码和响应头
6. 员工筛选、详情和新增
7. 404、409 和参数错误
8. 使用测试客户端验证接口

## 二、对比重点

与 FastAPI 第8章比较：Flask不会根据类型提示自动完成同等级别的解析、校验和接口文档，需要开发者明确处理或选择扩展。
