# 第1章 变量、类型与运算符

> 本章目标：理解变量、常量、数据类型、类型转换、输入输出和常用运算符。

## 一、变量是什么

- 变量是保存数据的名字
- 变量名要能表达业务含义
- 不建议使用 `a`、`b`、`temp` 这类没有信息量的名字

```python
user_name = "Tanaka"
user_age = 28
```

## 二、常量是什么

Python 没有强制常量语法，但企业项目里通常把“约定不修改的值”写成大写。

```python
PI = 3.1415926
MAX_RETRY_COUNT = 3
API_BASE_URL = "https://api.example.com"
```

## 三、常用数据类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `int` | 整数 | `10` |
| `float` | 小数 | `12.5` |
| `str` | 字符串 | `"Python"` |
| `bool` | 布尔值 | `True` |
| `None` | 空值 | `None` |

```python
count = 10
price = 12.5
name = "Python"
is_active = True
result = None
```

## 四、标识符是什么

标识符是程序里给变量、函数、类、模块等起的名字。

例如：

- `user_name` 是变量名
- `create_order` 是函数名
- `UserService` 是类名

### 4.1 标识符命名规则

Python 标识符需要遵守这些规则：

1. 只能由字母、数字、下划线组成
2. 不能以数字开头
3. 不能使用 Python 关键字
4. 区分大小写
5. 尽量使用有业务含义的名字

```python
user_name = "Tanaka"   # 正确
age2 = 28              # 正确
_temp_value = 10       # 正确

# 2name = "Tanaka"     # 错误，不能以数字开头
# class = "A"          # 错误，class 是关键字
```

### 4.2 什么是关键字

关键字是 Python 语言自己保留的单词，不能拿来直接当标识符使用。

常见关键字包括：

- `if`
- `else`
- `for`
- `while`
- `def`
- `class`
- `return`
- `True`
- `False`
- `None`

这些词有固定语法含义，所以不能随便当变量名、函数名或类名。

### 4.3 企业项目中的命名习惯

| 对象 | 命名方式 | 示例 |
| --- | --- | --- |
| 变量 | 小写加下划线 | `user_name` |
| 函数 | 动词 + 名词 | `create_order()` |
| 类 | 大驼峰命名 | `UserService` |
| 常量 | 全大写加下划线 | `MAX_RETRY_COUNT` |

### 4.4 不推荐的名字

- `a`
- `b`
- `temp`
- `data1`
- `aaa`

这些名字虽然能运行，但不利于阅读和维护。

## 五、类型查看与转换

```python
text = "123"
number = int(text)

print(type(number))  # <class 'int'>
```

常用方法：

| 函数 | 作用 | 示例 |
| --- | --- | --- |
| `type()` | 查看类型 | `type(value)` |
| `isinstance()` | 判断类型 | `isinstance(value, int)` |
| `int()` | 转整数 | `int("123")` |
| `float()` | 转小数 | `float("12.5")` |
| `str()` | 转字符串 | `str(100)` |
| `bool()` | 转布尔值 | `bool(1)` |

## 六、输入与输出

```python
name = input("请输入姓名：")
print(f"你好，{name}")  # 你好，Tanaka
```

`input()` 读取到的是字符串，后续计算前通常要先做类型转换。

## 七、运算符基础

### 7.1 算术运算符

| 运算符 | 作用 | 示例 |
| --- | --- | --- |
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b` |
| `//` | 整除 | `a // b` |
| `%` | 取余 | `a % b` |
| `**` | 幂运算 | `a ** b` |

### 7.2 比较运算符

| 运算符 | 作用 | 示例 |
| --- | --- | --- |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |

### 7.3 逻辑运算符

| 运算符 | 作用 | 示例 |
| --- | --- | --- |
| `and` | 并且 | `a > 0 and b > 0` |
| `or` | 或者 | `a > 0 or b > 0` |
| `not` | 取反 | `not is_active` |

### 7.4 赋值运算符

| 运算符 | 作用 | 示例 |
| --- | --- | --- |
| `=` | 赋值 | `a = 10` |
| `+=` | 加后赋值 | `a += 1` |
| `-=` | 减后赋值 | `a -= 1` |
| `*=` | 乘后赋值 | `a *= 2` |
| `/=` | 除后赋值 | `a /= 2` |

### 7.5 成员与身份运算符

| 运算符 | 作用 | 示例 |
| --- | --- | --- |
| `in` | 是否包含 | `"a" in "abc"` |
| `not in` | 是否不包含 | `"x" not in "abc"` |
| `is` | 是否同一个对象 | `a is b` |
| `is not` | 是否不是同一个对象 | `a is not b` |

## 八、常见错误

- 把 `input()` 的结果直接拿去做数值计算
- 变量名没有业务含义
- 把应当是常量的值写成魔法数字
- 把字符串和数字混在一起做加法

## 九、本章总结

- 变量用于保存数据
- 常量在企业项目里通常用大写约定
- 数据类型决定后续能做什么操作
- `input()`、`print()`、类型转换和运算符是后续章节的基础
