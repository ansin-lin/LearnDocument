## 三、终端是什么

终端是输入命令、查看结果的地方，也叫命令行界面。

常见终端：

| 系统 | 常见终端 | 说明 |
| --- | --- | --- |
| Windows | PowerShell、命令提示符 | Windows 默认命令环境 |
| macOS | Terminal、iTerm2 | macOS 下常见终端 |
| Linux | Terminal、Shell | Linux 下常见命令行环境 |

终端的作用：

- 启动程序
- 安装依赖
- 创建虚拟环境
- 切换目录
- 查看文件
- 运行测试

## 四、为什么要用终端

终端不是“可有可无”，而是开发环境的一部分。

原因如下：

- 很多开发工具最终都要通过命令执行
- 自动化脚本、测试脚本、部署脚本都依赖终端
- 企业项目里，开发、测试、运维都经常使用命令行
- 在日本项目现场，很多操作需要通过命令完成，而不是只点界面

## 七、终端执行过程

当你在终端执行：

```bash
python hello.py
```

大致会发生这些步骤：

1. 终端把命令发给系统
2. 系统找到 Python 解释器
3. Python 解释器读取 `hello.py`
4. 解释器逐行执行代码
5. 程序把结果输出到控制台

这就是“控制台执行程序”的基本过程。

控制台里看到的内容，通常就是程序运行后的输出结果、报错信息或者提示信息。

## 八、虚拟环境

虚拟环境用于隔离项目依赖，避免不同项目之间的库版本冲突。

### 8.1 为什么需要虚拟环境

如果多个项目共用同一个 Python 环境，可能会出现：

- 一个项目安装了新版本库，另一个项目却不兼容
- 卸载一个库时影响别的项目
- 不同项目需要不同版本的同一个库

所以要给每个项目准备自己的独立环境。

### 8.2 创建虚拟环境

```bash
python -m venv .venv
```

### 8.3 激活虚拟环境

Windows:

```bash
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

## 九、pip 是什么

`pip` 是 Python 的包管理工具，用于安装、卸载和管理第三方库。

常用命令：

```bash
python -m pip install requests
python -m pip list
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
```

推荐优先使用：

```bash
python -m pip
```

这样可以确保命令作用于当前 Python 环境，而不是系统里其他版本的 Python。

## 十一、常见环境问题

| 问题 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 找不到 `python` | 环境变量未配置 | 使用 `py` 或重新配置 PATH |
| `pip` 不可用 | Python 安装不完整 | 使用 `python -m pip` |
| 库安装失败 | 网络或权限问题 | 切换镜像、检查虚拟环境 |
| 运行不了 `.py` | 终端路径不对 | 切换到文件所在目录 |
