# 第8章 数据分析综合项目

前面几章学的是分步骤操作，这一章把它们连成一次完整交付。

## 8.1 项目目标

你现在是一名数据分析新人，需要基于零售订单数据完成一份基础分析，回答下面 4 个问题：

1. 总销售额和订单数是多少。
2. 哪个地区销售额最高。
3. 月度销售趋势如何。
4. 每月目标达成率是多少。

## 8.2 输入数据

项目使用下面 4 份数据：

```text
data/
├── orders.csv
├── customers.xlsx
├── products.csv
└── monthly_targets.csv
```

输出目录：

```text
output/
```

## 8.3 你需要完成的步骤

### 第一步：读取数据

- 读入 4 份数据
- 查看前几行
- 检查列名和数据类型

### 第二步：做第一次检查

- 统计缺失值
- 统计重复值
- 检查金额和日期是否读对

### 第三步：清洗数据

- 处理关键字段缺失
- 统一地区和品类写法
- 转换日期、金额、数量字段类型
- 处理明显异常值

### 第四步：补充分析字段

- 增加 `order_month`
- 必要时增加客户等级、商品品类等辅助信息

### 第五步：汇总分析

- 按地区统计销售额和订单数
- 按月份统计销售额趋势
- 关联目标表计算达成率

### 第六步：可视化与导出

- 生成地区销售额图
- 生成月度趋势图
- 导出 CSV 和 Excel 结果

## 8.4 建议输出结果

至少输出下面这些文件：

```text
output/
├── region_summary.csv
├── monthly_result.csv
└── analysis_report.xlsx
```

如果你已经能稳定完成，也可以继续扩展：

- 增加客户等级分析
- 增加品类分析
- 增加退款单排查结果

## 8.5 最低验收标准

项目完成后，至少要满足下面几点：

1. 数据能成功读取，不报错。
2. 关键字段的数据类型正确。
3. 清洗规则能说清楚，不是随意删除。
4. 分组统计结果口径明确。
5. 关联后的结果没有明显重复放大。
6. 图表标题、坐标轴和单位完整。
7. 结果文件能正常打开。

## 8.6 交付说明模板

可以按这个格式写一段简短说明：

> 本次分析基于零售订单数据，统计范围为指定时间段内的有效订单。处理过程中统一了地区和品类写法，剔除了关键字段缺失记录，并按月计算销售额、订单数和目标达成率。交付文件包含地区汇总、月度结果和 Excel 结果文件。

## 8.7 项目完成后，你应该达到的水平

做到这一章时，你不只是“会写几句 Pandas”，而是应该能独立走通下面这条链路：

读数 -> 检查 -> 清洗 -> 汇总 -> 画图 -> 导出 -> 说明结果

如果这条链路还走不顺，回到前面章节补齐具体薄弱点，不要直接跳到更复杂的机器学习或大数据主题。
