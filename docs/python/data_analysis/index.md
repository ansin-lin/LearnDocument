# Python 数据分析路线入口

这条路线按方案 A 重新整理后，核心结构变成：

- 主线：Excel / CSV 文件型数据分析
- 辅线：数据库读取分析与结果回写
- 收尾：综合练习

学习这条路线时，可以先按下面的理解来把握：

- Excel 和 CSV 的分析流程高度接近，可以放在同一条主线中学习
- 数据库分析需要额外处理连接、查询和结果回写，适合在文件型数据之后再学习
- 先掌握文件型数据分析，再扩展到数据库，更容易形成稳定的方法体系

## 本路线使用的数据

主线统一使用 `data/` 目录下的 4 份样例数据：

- `orders.csv`：订单明细
- `customers.xlsx`：客户资料
- `products.csv`：商品资料
- `monthly_targets.csv`：月度目标

这 4 份数据既能覆盖 Excel / CSV 主线，也能作为综合练习的数据源。

## 这条路线学完后应具备的能力

学完后，你应该至少能完成下面这些任务：

- 读取 Excel、CSV、数据库查询结果
- 识别并处理常见的缺失值、重复值、异常值
- 做基础汇总、透视、表关联
- 输出图表、CSV、Excel
- 把分析结果写回数据库或接到后续自动化流程

## 和自动化路线的边界

数据分析路线负责：

- 数据读入
- 数据检查
- 数据清洗
- 数据汇总
- 数据可视化
- 结果输出

自动化路线负责：

- 定时运行
- 批量生成报表
- 自动发邮件
- 批量处理文件
- 日志与失败重试

也就是说，数据分析路线先把“分析逻辑”建立起来，自动化路线再把“执行流程”接起来。
