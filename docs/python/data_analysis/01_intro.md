# 第1章 数据分析路线总览

这条路线默认你已经学过 Python 基础，不再重复讲变量、循环、函数等内容，而是直接进入“拿到业务数据后，如何完成一次基础分析”。

如果你还没有这些前置知识，请先回到：

- [Python 基础总览](../common/00_intro.md)
- [文件与数据处理](../common/10_file_data_processing.md)
- [PyMySQL 与数据库访问](../common/11_pymysql_database_access.md)

## 1.1 这条路线解决什么问题

学完后，你应该能独立完成下面这类任务：

- 读取 CSV 和 Excel 数据
- 检查字段类型、缺失值、重复值、异常值
- 用 Pandas 完成清洗、分组统计和表关联
- 输出基础图表和结果表
- 完成一个可交付的业务分析小项目

这条路线不以“把所有库都学完”为目标，而是以“能做完一条基础分析链路”为目标。

## 1.2 本路线的业务场景

后续章节统一使用“零售订单分析”场景，围绕下面 4 份数据展开：

```text
data_analysis_project/
├── data/
│   ├── orders.csv
│   ├── customers.xlsx
│   ├── products.csv
│   └── monthly_targets.csv
└── output/
```

四份文件分别表示：

- `orders.csv`：订单明细，核心事实数据
- `customers.xlsx`：客户资料
- `products.csv`：商品资料
- `monthly_targets.csv`：月度目标

你后面看到的示例代码、统计口径和最终项目，都会沿用这套场景，不会每一章换一个题目。

## 1.3 学习顺序

本路线按下面顺序推进：

1. 数据基础概念
2. 用 Pandas 读取数据并做第一次检查
3. 数据清洗与字段转换
4. 分组汇总、表关联与核心指标
5. 数据可视化
6. 手动导出 CSV 与 Excel 结果
7. 综合数据分析项目

这个顺序对应的是实际分析工作流：

先理解数据，再读数，再检查，再清洗，再统计，再表达结果。

## 1.4 环境约定

主线统一使用：

- Python 3
- `pandas`
- `matplotlib`

如果你的数据来自数据库，建议先用 SQL 或 Python 导出成 CSV，再走这条主线。数据库连接不是本路线重点，需要时回看 [PyMySQL 与数据库访问](../common/11_pymysql_database_access.md)。

如果你只需要“读取 Excel 文件”，后面章节会直接给出最小用法。

如果你要做的是：

- 固定模板 Excel 输出
- 多工作表报表交付
- 自动化批量生成 Excel

这些内容放在 [Python 自动化路线](../automation/index.md) 中讲，不在这里重复展开。

## 1.5 学完后的最低交付标准

完成这条路线后，至少要能交付下面这些结果：

- 一份清洗后的分析数据
- 一份按维度汇总的结果表
- 一份基础图表
- 一份手动导出的 CSV 或 Excel 结果
- 一段能说明结论和口径的文字

如果只能写出代码，但说不清“指标怎么算、结果能不能信、为什么是这个结论”，就还不算真正掌握。

## 1.6 和自动化路线的衔接

这条路线先解决“怎么把数据分析做出来”。

如果你接下来要做下面这些企业现场任务：

- 每天自动跑一次数据库查询
- 自动生成 Excel 报表
- 自动发邮件给上司或业务人员
- 把失败信息写入日志并支持重跑

这些内容应继续学习 [Python 自动化路线](../automation/index.md)。

也就是说：

- 数据分析路线负责分析逻辑本身
- 自动化路线负责把分析流程稳定落地
