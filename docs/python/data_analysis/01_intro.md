# 数据分析路线总览

这条路线现在不再按“先讲一堆库，再讲几个例子”的方式组织，而是按数据来源来组织。

这是因为学员在实际工作里最先面对的，不是库名，而是数据从哪里来。

## 为什么按数据来源来组织

企业里的数据分析任务，最常见的数据来源通常就是三类：

- Excel
- CSV
- 数据库

这三类里，Excel 和 CSV 的重合度很高：

- 都属于文件型数据
- 都要先读取文件
- 都会遇到表头、空值、类型、重复值问题
- 后续清洗、汇总、可视化、导出流程几乎一致

所以这条路线把它们合成一条主线。

数据库则不同：

- 需要连接数据库
- 需要写 SQL 查询
- 结果可能还要回写数据库

因此数据库适合作为主线后的专题。

## 新路线的学习顺序

### 第 1 步：先理解数据本身

先学：

- [数据基础概念](./02_data_concepts.md)

这里的目标不是写代码，而是先知道：

- 订单表、客户表、商品表、目标表分别是什么
- 什么是事实数据、主数据、目标数据
- 哪些字段适合做关联

### 第 2 步：主线学文件型数据分析

接着学：

- [Excel / CSV 读取与检查](./03_pandas_read_inspect.md)
- [Excel / CSV 数据清洗](./04_data_cleaning.md)
- [Excel / CSV 分组汇总、表关联与透视](./05_groupby_merge.md)
- [Excel / CSV 可视化与结果输出](./06_visualization.md)

这一段是整条路线的主体。

你会重点掌握：

- 读取文件型数据的方法
- 清洗数据的方法
- 汇总、透视、合并的方法
- 输出分析结果的方法

### 第 3 步：再学数据库分析

然后学：

- [数据库读取分析与结果回写](./07_excel_csv_report.md)

这里不再重复数据库基础，只关注：

- `pandas` 怎么接数据库
- 怎么把 SQL 结果读进来分析
- 怎么把结果写出去

### 第 4 步：做综合练习

最后学：

- [综合练习：四份数据的销售分析与报表输出](./08_analysis_project.md)

这一步的目标是：

- 用 4 份样例数据把整条主线串起来
- 完成一套相对完整的分析结果

## 这条路线的写法标准

从第 03 章开始，章节会以“方法 + 参数 + 场景”为主，而不是把每章写成业务叙事文。

重点方法会用完整模板讲：

1. 原始数据或原始问题
2. 数据特点
3. 完整代码
4. 参数说明
5. 运行结果
6. 使用场景
7. 什么时候不用
8. 常见错误

辅助方法则用简化模板讲：

1. 方法作用
2. 常用参数
3. 简单示例
4. 使用场景
5. 注意点

## 学完这条路线后，你应该做到什么

至少能够独立完成：

- 从 Excel / CSV 读取数据
- 清洗和检查数据
- 汇总分析和表关联
- 输出图表、CSV、Excel
- 从数据库读结果做分析
- 把结果回写数据库或继续交给后续自动化流程

这就是这条路线重构后的目标。
