# Python 自动化路线

这条路线讲日本项目里的 Python 业务自动化，也就是把重复、固定、容易出错的业务操作写成脚本，让程序按规则稳定执行。

本路线不讲 AI，不讲桌面自动点击，也不重复 Python 基础、数据分析和 Web 开发中已经讲过的完整内容。

自动化课程重点解决这些问题：

- 文件在哪里，如何检查、移动、备份、归档。
- CSV、Excel、JSON 如何在自动化流程中读取和输出。
- 多个文件、多个日期、多个对象如何批量处理。
- 如何调用已有接口。
- 如何发送邮件或通知。
- 如何让脚本定时运行。
- 如何记录日志、处理异常、失败后重试。
- 如何把脚本做成可交付、可维护的企业自动化流程。

## 和其他 Python 路线的关系

数据分析路线已经讲过 Pandas 的读取、清洗、分组、合并、可视化和数据库分析。自动化路线不会重复这些分析方法，只在项目中调用它们完成报表流程。

Web 路线讲接口如何开发。自动化路线只讲脚本如何调用已有接口。

Python 基础已经讲过变量、函数、异常、文件和数据库连接。自动化路线会直接使用这些基础能力，把它们组合成企业现场可执行的流程。

## 自动化脚本的交付标准

一个脚本不是“能跑一次”就算完成。企业自动化脚本至少要做到：

- 有固定入口，可以被别人或调度器执行。
- 输入路径、输出路径、处理日期可以配置。
- 成功时生成可检查的结果文件。
- 失败时有错误信息和日志。
- 重复执行不会把结果弄乱。
- 不随便删除、覆盖正式数据。
- 可以交接给其他成员维护。
