# 员工管理系统：贯穿式教学项目总览

> 项目中文名：员工管理系统  
> 项目英文名：Employee Management System  
> 项目日文名：社員管理システム  
> 项目简称：EMS

## 一、项目定位

员工管理系统是本教学文档的 Web 开发贯穿项目，用于连接前端、后端、数据库、测试、Git、Linux 和部署课程。

项目采用前后端分离架构：

```text
Vue / React 前端
       ↓ HTTP + JSON
FastAPI / Django REST Framework / Spring Boot 后端
       ↓ SQL / ORM / MyBatis
关系型数据库
```

不同技术路线可以实现同一套业务，但页面、字段、接口语义和业务规则应保持一致。

## 二、为什么选择员工管理系统

这个项目包含企业 Web 开发中常见的内容：

- 登录认证
- 角色与权限
- 列表查询和分页
- 新增、修改和逻辑删除
- 表单校验
- 部门与员工关联
- CSV 批量导入
- Excel 报表导出
- 日志和异常处理
- 前后端接口联调
- 自动化测试
- Linux 和容器部署

项目规模可以逐章扩展，又不会在新人阶段引入支付、复杂库存或分布式事务等过重业务。

## 三、学习者最终成果

完成对应课程后，学员应能够：

- 看懂项目要件定义和接口定义
- 根据页面需求设计前端组件
- 根据接口契约实现后端 API
- 设计员工、部门和账号相关数据表
- 实现参数校验、业务规则和权限控制
- 完成 CSV 导入和 Excel 导出
- 编写正常、异常和边界测试
- 使用 Git 完成功能分支和 Review
- 在 Linux 或容器环境中启动应用
- 说明修改目的、影响范围和验证结果

## 四、项目范围

### 4.1 第一阶段必须实现

- 用户登录和退出
- 员工列表、详情、新增、修改和逻辑删除
- 员工姓名、部门和状态筛选
- 分页和排序
- 部门列表和维护
- 基础角色权限
- 统一错误响应
- 操作日志
- CSV 员工导入
- Excel 员工报表导出
- 后端接口测试
- 前端主要页面测试

### 4.2 后续扩展

- 密码修改和重置
- 员工头像上传
- 批量状态修改
- 审批流程
- 邮件通知
- 定时生成报表
- 云端对象存储
- 缓存和性能优化

### 4.3 不在基础项目范围内

- 工资和奖金计算
- 考勤打卡
- 复杂组织树
- 多租户
- 微服务拆分
- 分布式事务
- 真实个人身份信息

## 五、用户角色

| 角色代码 | 中文名称 | 主要权限 |
| --- | --- | --- |
| `SYSTEM_ADMIN` | 系统管理员 | 账号、角色、员工、部门和日志管理 |
| `HR_STAFF` | 人事担当 | 员工和部门维护、导入导出 |
| `VIEWER` | 只读用户 | 查看员工和部门信息 |

权限采用“默认拒绝”原则。用户没有被明确授予的操作，不应只靠隐藏前端按钮来限制，后端也必须校验。

## 八、系统架构

### 8.1 逻辑架构

```text
浏览器
  ↓
前端应用
  ├── 页面与组件
  ├── 路由
  ├── 表单校验
  └── API 客户端
        ↓ HTTP / JSON
后端应用
  ├── Controller / Router
  ├── Service
  ├── Repository / Mapper
  ├── 认证与权限
  └── 日志与异常
        ↓
关系型数据库 / 文件存储
```

### 8.2 技术实现可以替换

| 层 | 可选技术 |
| --- | --- |
| 前端 | Vue + TypeScript 或 React + TypeScript |
| Python 后端 | FastAPI 或 Django REST Framework |
| Java 后端 | Spring Boot + MyBatis |
| 数据库 | PostgreSQL 为推荐实现，基础练习可使用 SQLite |
| 测试 | pytest、JUnit、Vitest/Jest、Playwright |
| 部署 | Linux、Docker、反向代理，后续可扩展 AWS |

课程不会要求新人同时完成所有实现。学员选择一条前端路线和一条后端路线即可。

## 十、开始学习前的使用方式

1. 先阅读项目总览和要件定义。
2. 当前章节只实现教学要求的范围。
3. 字段和接口名称以共享规格为准。
4. 暂未学习的功能可以使用固定数据或 Mock。
5. 每章结束后将新知识加入同一个项目。
6. 修改共享契约时，同时检查前端、后端、数据库和测试影响。
