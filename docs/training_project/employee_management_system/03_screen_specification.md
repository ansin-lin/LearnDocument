# 员工管理系统画面规格

> 本文件定义 Vue 和 React 路线共同遵守的页面功能。组件库和视觉主题可以不同，但页面状态、字段、权限和 API 契约必须一致。

## 一、共通画面规则

- 页面必须支持加载中、无数据、成功和失败状态
- 表单提交期间避免重复提交
- 前端校验用于改善体验，后端必须再次校验
- 权限不足时不显示无权限操作，同时处理后端 `403`
- 登录失效时统一引导重新登录
- 错误提示不展示堆栈、SQL 或内部路径
- 表单控件必须有可识别标签
- 键盘操作和焦点顺序应合理
- 表格在窄屏下应可滚动或转换布局

## 三、登录页

### 3.1 输入项目

| 字段 | 必填 | 规则 |
| --- | :---: | --- |
| 登录 ID | 是 | 去除首尾空格，不在错误中泄露账号存在性 |
| 密码 | 是 | 密码输入框，不回显明文 |

### 3.2 操作

- 点击登录后显示处理中状态
- 成功后进入首页
- 失败显示统一登录错误
- 连续点击不能重复提交

### 3.3 页面状态

- 初始状态
- 输入错误状态
- 登录处理中
- 登录失败
- 登录成功跳转

## 四、员工列表页

### 4.1 查询条件

| 条件 | 控件 | 说明 |
| --- | --- | --- |
| 员工姓名 | 文本框 | 部分匹配 |
| 部门 | 下拉框 | 从部门 API 取得 |
| 状态 | 下拉框 | ACTIVE、LEAVE、RETIRED |

### 4.2 表格列

- 员工编号
- 姓名
- 邮箱
- 部门
- 入职日期
- 状态
- 更新时间
- 操作

### 4.3 操作

- 查询
- 清除条件
- 查看详情
- 新增员工
- 编辑员工
- 逻辑删除员工
- CSV 导入
- Excel 导出
- 切换分页和排序

按钮应根据角色显示。即使按钮隐藏，后端仍需校验权限。

### 4.4 页面状态

| 状态 | 表现 |
| --- | --- |
| 加载中 | 显示加载提示，避免误操作 |
| 查询成功 | 显示表格和分页 |
| 无数据 | 显示“没有符合条件的数据” |
| 查询失败 | 显示错误和重试入口 |
| 删除确认 | 显示员工编号和影响说明 |
| 删除成功 | 刷新列表并显示结果 |
| 删除冲突 | 提示数据已更新，要求重新加载 |

## 五、员工新增与编辑页

### 5.1 表单字段

| 字段 | 新增 | 编辑 | 控件 |
| --- | :---: | :---: | --- |
| 员工编号 | 必填 | 只读 | 文本框 |
| 姓名 | 必填 | 必填 | 文本框 |
| 邮箱 | 必填 | 必填 | 邮箱输入框 |
| 部门 | 必填 | 必填 | 下拉框 |
| 入职日期 | 必填 | 必填 | 日期选择 |
| 状态 | 必填 | 必填 | 下拉框 |
| version | 隐藏 | 必须提交 | 隐藏状态 |

### 5.2 校验

- 必填检查
- 员工编号格式
- 姓名长度
- 邮箱格式
- 部门是否选择
- 入职日期格式
- 状态是否合法

前端不能完成员工编号唯一、邮箱唯一和部门有效性的最终判断，这些由后端验证。

### 5.3 编辑冲突

后端返回 `OPTIMISTIC_LOCK_CONFLICT` 时：

1. 不覆盖服务器数据。
2. 提示数据已经被其他用户修改。
3. 提供重新加载入口。
4. 不自动丢弃用户输入，具体保留方式由实现决定。

## 六、部门管理页

- 显示部门编号、名称、有效状态和更新时间
- 支持新增和修改
- 部门编号创建后不可修改
- 停用前显示影响确认
- 存在有效员工时，展示不能停用的业务错误

## 七、CSV 导入页

### 7.1 初始状态

- 显示文件格式、编码、大小和行数限制
- 提供 CSV 模板下载入口
- 只允许选择一个文件

### 7.2 导入状态

- 文件选择完成
- 上传中
- 校验中
- 全部成功
- 存在错误
- 网络或服务器失败

### 7.3 错误显示

错误表格包含：

- 行号
- 字段
- 错误代码
- 错误信息

不要只显示“导入失败”。学员应能根据结果定位到具体数据。

## 八、操作日志页

只有系统管理员可以访问。

查询条件：

- 操作者
- 操作类型
- 业务对象
- 开始时间
- 结束时间
- 处理结果

表格不得显示密码、完整 Token 或秘密值。

## 九、前后端交互规则

- API 基础路径从环境配置读取
- 所有请求统一处理认证失效和网络错误
- 请求失败时保留必要上下文用于重试
- 取消或切换页面时避免旧请求覆盖新结果
- 表单提交成功后按页面规则刷新或跳转
- 下载文件时处理文件名和错误响应
- 前端日志不记录秘密和个人敏感信息

## 十、基础验收观点

每个页面至少确认：

- 初始显示
- 加载状态
- 正常数据
- 空数据
- 输入错误
- 后端业务错误
- `401`、`403`、`404`、`409`、`500`
- 连续点击
- 刷新和返回
- 权限差异
- 键盘操作
- 不同窗口宽度
