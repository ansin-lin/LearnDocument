## 学习建议

1. 先完成前两周考察期的 SQL 和 Java 基础。
2. 通过考察后，再按前端、后端、工具三条主线展开学习。
3. Python 课程可作为独立主线学习，也可作为工程能力补充。
4. 每门课程都建议按“概念 -> 语法 -> 示例 -> 企业场景 -> 日本项目使用方式”阅读。

## 编写原则

- 讲解尽量贴近企业开发场景
- 优先考虑日本项目开发现场的写法和表达
- 代码示例要尽量可运行
- 每章尽量包含总结、练习和面试关注点
