# Java 基础教程

本教程面向 Java 零基础学员。课程从 Java 程序结构开始，逐步进入类型、流程控制、类与对象、集合、文件、数据库连接和 Maven。

## 课程顺序

| 章节 | 内容 | 学习重点 |
| --- | --- | --- |
| 1 | Java 入门简介 | 理解 Java 能做什么 |
| 2 | Java 程序结构 | 看懂类、main 方法和运行入口 |
| 3 | 变量与常量 | 理解字段、参数和局部变量 |
| 4 | 运算符 | 支撑条件判断和计算逻辑 |
| 5 | 流程控制 | 编写判断、循环和分支 |
| 6 | 数组 | 理解一组数据的基础处理 |
| 7 | 字符串基础 | 处理名称、状态、请求参数 |
| 8 | 类与对象基础 | 理解类、对象、属性和引用 |
| 9 | 方法基础 | 理解方法定义、参数和返回值 |
| 10 | 构造方法、封装与 JavaBean | 理解对象初始化和属性保护 |
| 11 | 继承、重写与多态 | 理解父类、子类和多态调用 |
| 12 | static、final、抽象类、接口与内部类 | 理解常量、工具类、接口编程和简单内部类 |
| 13 | 包、import 与 JAR 文件 | 理解包结构和 Java 工程组织 |
| 14 | 异常处理 | 理解错误处理和异常传递 |
| 15 | 集合框架 | 处理多个数据和键值对数据 |
| 16 | 泛型 | 理解 `List<String>`、`Box<T>` |
| 17 | 字符串相关类与枚举 | 理解字符串拼接、分隔符拼接和固定状态值 |
| 18 | 常用类 | 处理金额、日期、工具类 |
| 19 | I/O 与文件处理 | 理解文件读取、写入和资源关闭 |
| 20 | Maven 基础 | 理解依赖管理和构建命令 |
| 21 | JDBC 数据库连接 | 理解 Java 连接数据库的基础方式 |
