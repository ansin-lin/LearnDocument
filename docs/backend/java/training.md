# Java 语法与逻辑综合练习 100 题


## 原有练习：基础逻辑50题

### 1. 斐波那契数列——兔子繁殖问题

有一对兔子，出生后的前两个月不繁殖，从第3个月开始每个月生一对兔子，新兔子遵循相同规律且兔子不死亡。输入月份 `n`，输出前 `n` 个月每月的兔子对数。

示例：输入 `8`，输出 `1 1 2 3 5 8 13 21`。

### 2. 指定范围内的素数

输出101～200之间的全部素数，并统计数量。

示例输出应包含 `101、103、107` 等数。

### 3. 水仙花数

输出所有三位水仙花数。三位数各位数字的立方和等于原数时，它是水仙花数。

示例：`153 = 1³ + 5³ + 3³`。

### 4. 分解质因数

输入一个大于1的正整数，将它分解成质因数并按从小到大输出。

示例：输入 `90`，输出 `90 = 2 × 3 × 3 × 5`。

### 5. 条件运算符

输入0～100的成绩，只使用条件运算符完成分级：90分及以上为A，60～89为B，低于60为C。范围外输出 `成绩无效`。

示例：输入 `85`，输出 `B`。

### 6. 最大公约数和最小公倍数

输入两个正整数，使用辗转相除法求最大公约数，并计算最小公倍数。

示例：输入 `18 24`，输出 `最大公约数=6，最小公倍数=72`。

### 7. 统计字符串中的字符类型

输入一行字符串，分别统计英文字母、数字、空格和其他字符的数量。

示例：输入 `Java 17!`，输出 `字母=4，数字=2，空格=1，其他=1`。

### 8. 求a + aa + aaa + ...的值

输入数字 `a`（1～9）和项数 `n`（正整数），计算 `a + aa + aaa + ...` 的前 `n` 项之和。

示例：输入 `2 5`，计算 `2 + 22 + 222 + 2222 + 22222`。

### 9. 查找完数

输出1000以内的全部完数。一个正整数的所有真因子（不包含自身）之和等于它本身时，它是完数。

示例：`6 = 1 + 2 + 3`。

### 10. 小球反弹问题

小球从100米落下，每次反弹到原高度的一半。计算第10次落地时经过的总路程，以及第10次反弹的高度。总路程不包含第10次反弹后的上升距离。

### 11. 三位数排列组合

使用数字1、2、3、4组成数字不重复的三位数，输出全部结果并统计数量。

示例结果包含 `123、124、132`。

### 12. 阶梯奖金计算

输入非负利润（单位：万元），按以下各区间的部分分别计提奖金：0～10为10%，10～20为7.5%，20～40为5%，40～60为3%，60～100为1.5%，超过100为1%。

示例：利润25万元的奖金为 `10×10% + 10×7.5% + 5×5%`。

### 13. 求满足条件的整数

在0～100000中找出全部整数 `n`，使 `n + 100` 和 `n + 268` 都是完全平方数。

### 14. 日期计算

输入合法的年、月、日，计算它是当年的第几天。必须正确处理闰年。

示例：输入 `2024 3 5`，输出 `65`。

### 15. 三个整数排序

输入三个整数，不使用数组和现成排序方法，按从小到大输出。

示例：输入 `8 3 5`，输出 `3 5 8`。

### 16. 九九乘法表

使用双重循环输出下三角形式的九九乘法表，每行从 `1×行号` 输出到 `行号×行号`。

### 17. 猴子吃桃——逆向计算

猴子每天吃掉现有桃子的一半并多吃1个，第10天早上剩1个。使用逆向计算求第一天最初的桃子数。

### 18. 乒乓球比赛配对

甲队为a、b、c，乙队为x、y、z，每人只比赛一次。已知a不和x比赛，c不和x、z比赛，输出三组配对。

### 19. 打印菱形

使用循环打印7行菱形：

```text
   *
  ***
 *****
*******
 *****
  ***
   *
```

### 20. 分数数列求和

数列为 `2/1、3/2、5/3、8/5...`，后一项分子等于前一项分子加分母，后一项分母等于前一项分子。计算前20项之和。

### 21. 阶乘求和

计算 `1! + 2! + ... + 20!`，使用 `long` 保存阶乘和结果。

### 22. 递归计算阶乘

使用递归计算 `5!`，递归终止条件必须覆盖 `0! = 1`。

### 23. 递归计算年龄

第1个人10岁，后一个人总比前一个人大2岁。编写递归方法计算第5个人的年龄。

### 24. 整数位数与倒序输出

输入一个不超过5位的正整数，输出位数，并从个位到最高位逐个输出数字。

示例：输入 `12345`，输出 `位数=5，倒序=5 4 3 2 1`。

### 25. 判断回文数

输入一个五位正整数，判断它是否为回文数。

示例：输入 `12321`，输出 `true`。

### 26. 根据英文星期名称判断星期

输入完整英文星期名称，忽略大小写，输出对应中文星期。必须区分首字母相同的Tuesday/Thursday和Saturday/Sunday；其他输入输出 `无效星期`。

### 27. 求100以内的素数

输出2～100之间的全部素数。

### 28. 选择排序

输入10个整数，不调用现成排序方法，使用选择排序按升序输出。

### 29. 3×3矩阵主对角线求和

输入3×3整数矩阵，计算主对角线 `a[i][i]` 的元素之和。

示例：`[[1,2,3],[4,5,6],[7,8,9]]` 的结果为15。

### 30. 有序数组插入

给定升序数组和一个整数，创建长度加1的新数组，把该整数插入正确位置，使结果仍为升序。

示例：`[1,3,5,7,9]` 插入6，得到 `[1,3,5,6,7,9]`。

### 31. 数组逆序

通过首尾交换将整数数组原地逆序，不创建同长度的新数组。

示例：`[1,2,3,4,5]` 变为 `[5,4,3,2,1]`。

### 32. 查找数组中第二大的不同数字

输入整数数组，找出第二大的不同数字；不足两个不同值时输出 `不存在`。

示例：`[5,3,9,7,9,2]` 输出7。

### 33. 杨辉三角

使用二维数组打印杨辉三角前10行，每行首尾为1，中间元素等于上一行相邻两数之和。

### 34. 三个数字排序——数组方式

把三个整数保存到数组中，不调用现成排序方法，通过比较和交换按升序输出。

### 35. 数组最大值、最小值交换

输入非空整数数组，把最大值与第一个元素交换，再重新查找最小值并与最后一个元素交换，输出结果数组。

### 36. 数组循环右移

输入非空整数数组和非负整数 `m`，把数组整体循环右移 `m` 位；当 `m` 大于数组长度时先取模。

示例：`[1,2,3,4,5]` 右移2位得到 `[4,5,1,2,3]`。

### 37. 约瑟夫环问题

`n` 个人编号1～n围成一圈，从1开始循环报数，报到3的人退出，求最后留下者的原编号。`n` 为正整数。

### 38. 计算字符串长度

输入字符串，不把 `String.length()` 作为核心计数方式，先转换成字符数组，再通过增强for循环累计字符数量。

示例：输入 `hello`，输出5。

### 39. 奇偶不同规则的分数求和

输入正整数 `n`。偶数时计算 `1/2 + 1/4 + ... + 1/n`；奇数时计算 `1/1 + 1/3 + ... + 1/n`。使用浮点除法。

### 40. 字符串排序

输入若干个非空英文字符串，区分大小写并使用 `compareTo()` 比较，不调用数组或集合整体排序方法，按字典顺序输出。

### 41. 五只猴子分桃

五只猴子依次处理桃子：每次都分成5份且多1个，扔掉多出的1个并拿走一份。求最开始最少有多少个桃子。

### 42. 条件枚举

找出全部两位正整数 `x`，使 `8×x` 是两位数且 `9×x` 是三位数；输出 `x` 和 `809×x`。

### 43. 使用0～7组成三位奇数

使用0～7组成没有重复数字的三位正奇数，百位不能为0，输出全部结果并统计数量。

### 44. 偶数分解为两个奇数

输入大于2的偶数 `n`，输出所有满足 `a + b = n`、`a <= b` 的正奇数组合。这里不要求a和b是素数。

示例：输入10，输出 `1+9、3+7、5+5`。

### 45. 连续被9整除

输入正整数，判断它最多可以连续被9整除多少次。

示例：输入729，输出3。

### 46. 字符串连接

输入两个字符串，不使用 `concat()`，把第二个字符串连接到第一个字符串之后。

示例：输入 `Hello` 和 `World`，输出 `HelloWorld`。

### 47. 打印星号

连续读取7个1～50之间的整数，每读取一个数字就单独打印一行对应数量的 `*`；范围外要求重新输入当前数字。

### 48. 四位数字加密

输入0000～9999范围的整数。每位加5后对10取余，再交换第一与第四位、第二与第三位，最终始终按4位格式输出。

### 49. 统计子串出现次数

输入原字符串和非空子串，统计允许重叠、区分大小写时的出现次数。空子串输出 `子串不能为空`。

示例：`aaaa` 中 `aa` 出现3次。

### 50. 学生成绩平均值

输入5名学生的学号、姓名和3门0～100分的成绩，计算每名学生的平均分并输出；再以UTF-8覆盖写入当前目录的 `stud.txt`。每行格式为 `学号,姓名,成绩1,成绩2,成绩3,平均分`。

## 新增练习：扩展语法与应用

## 第一阶段：变量、运算符与流程控制

### 51. 温度转换

输入摄氏温度 `c`，计算华氏温度：`f = c × 9 / 5 + 32`。结果保留1位小数。

示例：输入 `25`，输出 `77.0`。

### 52. 分段电费

输入本月用电量（非负整数）。前100度每度0.50元，101～200度部分每度0.60元，超过200度部分每度0.80元，计算总电费。

示例：输入 `250`，输出 `150.00`。

### 53. 闰年判断

输入年份，判断是否为闰年。能被400整除，或能被4整除但不能被100整除的年份是闰年。

示例：输入 `2024`，输出 `闰年`；输入 `1900`，输出 `平年`。

### 54. 成绩等级

输入0～100的整数成绩：90～100为A，80～89为B，70～79为C，60～69为D，低于60为E。范围外输出 `成绩无效`。

示例：输入 `86`，输出 `B`。

### 55. 三个整数的中间值

输入三个整数，输出大小处于中间的值。三个数可能相等，不允许使用数组排序。

示例：输入 `8 3 5`，输出 `5`。

### 56. 最大公约数与最小公倍数

输入两个正整数，使用辗转相除法求最大公约数，并计算最小公倍数。计算最小公倍数时先做除法再做乘法。

示例：输入 `18 24`，输出 `最大公约数=6，最小公倍数=72`。

### 57. 素数判断

输入大于1的整数 `n`，只检查到 `sqrt(n)`，判断它是否为素数。

示例：输入 `29`，输出 `true`；输入 `35`，输出 `false`。

### 58. 斐波那契数列

输入 `n`（1～50），输出前 `n` 项斐波那契数列。前两项为1，从第3项起等于前两项之和。

示例：输入 `7`，输出 `1 1 2 3 5 8 13`。

### 59. 数字拆分与反转

输入一个不超过9位的正整数，输出位数、各位数字之和以及反转后的整数。反转结果允许丢失前导0。

示例：输入 `12030`，输出 `位数=5，数字和=6，反转=3021`。

### 60. 打印空心矩形

输入高度 `h` 和宽度 `w`（均不小于2），使用 `*` 打印空心矩形。

示例：输入 `3 5`：

```text
*****
*   *
*****
```

## 第二阶段：数组与字符串

### 61. 数组统计

给定整数数组，输出最大值、最小值、总和及平均值。数组至少包含一个元素，平均值保留2位小数。

示例：`[4, 7, 1, 8]` 输出 `最大值=8，最小值=1，总和=20，平均值=5.00`。

### 62. 原地逆序数组

不创建第二个数组，通过首尾交换将整数数组原地逆序。

示例：`[1, 2, 3, 4, 5]` 变为 `[5, 4, 3, 2, 1]`。

### 63. 第二大的不同数字

在整数数组中找出第二大的不同数字。数组不足两个不同值时输出 `不存在`，并正确处理负数和 `Integer.MIN_VALUE`。

示例：`[5, 9, 7, 9, 2]` 输出 `7`；`[3, 3]` 输出 `不存在`。

### 64. 选择排序

不调用现成排序方法，使用选择排序将整数数组按升序排列。

示例：`[6, 2, 8, 1]` 变为 `[1, 2, 6, 8]`。

### 65. 有序数组插入

给定升序数组和待插入整数，创建长度加1的新数组，将所有元素复制到正确位置，使结果仍为升序。相等元素可放在已有相等元素之后。

示例：数组 `[1, 3, 5, 7]` 插入 `5`，输出 `[1, 3, 5, 5, 7]`。

### 66. 矩阵对角线

给定一个非空正方形二维整数数组，分别计算主对角线与副对角线元素之和。

示例：矩阵 `[[1,2,3],[4,5,6],[7,8,9]]` 输出 `主对角线=15，副对角线=15`。

### 67. 字符类型统计

输入一行文本，统计英文字母、数字、空白字符和其他字符的数量。空白使用 `Character.isWhitespace()` 判断。

示例：输入 `Java 17!`，输出 `字母=4，数字=2，空白=1，其他=1`。

### 68. 忽略格式判断回文

判断字符串是否为回文。比较时忽略大小写，并忽略所有非字母、非数字字符。

示例：输入 `A man, a plan, a canal: Panama`，输出 `true`。

### 69. 重叠子串计数

输入原字符串和非空子串，统计允许重叠时子串出现的次数。大小写敏感；子串为空时输出 `子串不能为空`。

示例：原字符串 `aaaa`、子串 `aa`，输出 `3`。

### 70. 简单字符串压缩

将连续重复字符转换成“字符＋次数”。字符比较区分大小写，即使只出现1次也要写次数。

示例：输入 `aaabbc`，输出 `a3b2c1`；空字符串输出空字符串。

## 第三阶段：方法、递归与面向对象

### 71. 提取素数方法

编写 `static boolean isPrime(int n)`，再调用它输出2～100之间的全部素数。`n < 2` 时返回 `false`。

示例：`isPrime(97)` 返回 `true`。

### 72. 方法重载计算面积

定义同名方法 `area`：`area(double radius)` 计算圆面积，`area(double width, double height)` 计算矩形面积。尺寸必须大于0，否则抛出 `IllegalArgumentException`。

示例：`area(2.0)` 约为 `12.5664`，`area(3.0, 4.0)` 为 `12.0`。

### 73. 递归阶乘

编写递归方法计算 `n!`，只接受0～20；范围外抛出 `IllegalArgumentException`，并使用 `long` 返回结果。

示例：输入 `5`，返回 `120`。

### 74. 递归计算各位数字之和

编写递归方法，计算非负整数各位数字之和。

示例：输入 `5072`，返回 `14`。

### 75. 可变参数统计

编写 `static double average(int... values)` 计算任意个整数的平均值；没有参数时抛出 `IllegalArgumentException`。

示例：`average(2, 4, 6)` 返回 `4.0`。

### 76. Student类

定义 `Student` 类，包含只读学号、姓名以及3门成绩。通过构造方法初始化；提供平均分方法和 `toString()`。成绩必须在0～100之间，否则抛出异常。

示例：学生 `S001, Tanaka, 80, 90, 100` 的平均分为 `90.0`。

### 77. BankAccount封装

定义银行账户类：账号只读，余额只能通过 `deposit` 和 `withdraw` 改变。存款必须大于0；取款必须大于0且不能超过余额，非法操作抛出异常。

示例：初始余额1000，存入500并取出300，最终余额为1200。

### 78. static对象计数

定义 `Employee` 类，每创建一个对象，静态计数器加1；提供静态方法读取已创建对象数。编号和姓名通过构造方法传入。

示例：连续创建3个对象后，计数为3。

### 79. 继承与方法重写

定义父类 `Employee`，包含姓名和基本月薪；子类 `Manager` 增加月度奖金并重写 `calculateSalary()`，返回基本月薪加奖金。

示例：基本月薪300000、奖金50000，经理工资为350000。

### 80. 接口与多态

定义 `Shape` 接口，声明 `double area()`；实现 `Circle` 和 `Rectangle`。把不同形状放入 `Shape[]`，计算总面积。所有尺寸必须大于0。

示例：半径1的圆和2×3矩形，总面积约为 `9.1416`。

### 81. 枚举与状态判断

定义订单状态枚举 `CREATED`、`PAID`、`SHIPPED`、`COMPLETED`、`CANCELLED`，编写方法判断某状态是否为结束状态。只有 `COMPLETED` 和 `CANCELLED` 是结束状态。

示例：`isFinished(COMPLETED)` 返回 `true`。

### 82. JavaBean商品对象

定义 `Product` JavaBean，包含 `Long id`、`String name`、`BigDecimal price`，提供无参数构造方法、getter和setter。价格不能小于0。

示例：设置名称 `Keyboard`、价格 `299.00` 后，getter返回相同数据。

## 第四阶段：异常、集合与泛型

### 83. 安全解析整数

编写方法接收字符串并转换为整数。转换成功返回整数；遇到 `null`、空白或格式错误时返回 `OptionalInt.empty()`，不得使用空 `catch`。

示例：输入 `" 42 "` 得到42；输入 `"4a"` 得到空结果。

### 84. 自定义年龄异常

创建受检异常 `InvalidAgeException`。`register(int age)` 只接受18～65岁，范围外抛出该异常；调用方必须捕获或继续声明。

示例：输入17，输出异常消息 `年龄必须在18到65之间`。

### 85. List去重并保持顺序

输入 `List<String>`，删除重复项并保持第一次出现的顺序，返回新的List，不能修改原List。

示例：`[A, B, A, C, B]` 返回 `[A, B, C]`。

### 86. Set求交集

输入两个 `Set<Integer>`，返回同时存在于两个集合的元素集合，不修改原集合。

示例：`{1,2,3}` 与 `{2,3,4}` 的交集是 `{2,3}`。

### 87. Map统计单词

输入只含英文单词和空格的文本，忽略大小写，使用 `Map<String, Integer>` 统计每个单词出现次数。多个空格视为一个分隔区域，空白输入返回空Map。

示例：`Java java Spring` 得到 `{java=2, spring=1}`。

### 88. Comparator排序员工

给定员工对象列表，先按部门升序，再按姓名升序排列；不能修改原列表。部门或姓名均不为 `null`。

示例：`Sales/Tanaka, Dev/Suzuki, Dev/Aoki` 排序后为 `Dev/Aoki, Dev/Suzuki, Sales/Tanaka`。

### 89. Queue窗口排队

使用 `Queue<String>` 模拟窗口排队：按顺序加入 `A、B、C`，服务并移除队首两人，输出服务顺序和剩余队列。

示例：服务顺序为 `A、B`，剩余 `[C]`。

### 90. Deque括号匹配

使用 `Deque<Character>` 判断只含 `()`、`[]`、`{}` 的字符串括号是否正确匹配。空字符串视为正确。

示例：`{[()]}` 返回 `true`，`([)]` 返回 `false`。

### 91. 泛型Box

定义泛型类 `Box<T>`，通过构造方法保存一个值，并提供 `getValue()`。分别创建 `Box<String>` 和 `Box<Integer>`。

示例：字符串Box返回 `Java`，整数Box返回 `17`。

### 92. 泛型方法获取最后一个元素

编写 `static <T> Optional<T> last(List<T> list)`。列表为空时返回 `Optional.empty()`，否则返回最后一个元素；不修改列表。

示例：`[A, B, C]` 返回包含 `C` 的Optional。

### 93. BigDecimal订单金额

### 95. 日期范围内的工作日

### 96. 使用StringBuilder生成CSV行

输入字符串数组，使用 `StringBuilder` 连接成一行逗号分隔文本。本题输入字段不包含逗号、双引号或换行。
