# 第 1 章：Linux 基础认识与环境准备

学完本章，你应能说清 Linux、Windows、服务器和操作系统的关系，打开一个 Linux 终端，并自己执行 `whoami`、`pwd`、`date`。文件与目录操作从[下一章](02_file_dir_command.md)开始。

## 1.1 操作系统是什么

操作系统管理计算机的硬件与文件，并为应用程序提供运行环境。你在电脑上使用的 Windows、服务器上可能使用的 Linux，都是操作系统；“服务器”指承担服务任务的计算机或运行环境，**不是另一种操作系统**。服务器可以运行 Linux，也可以运行 Windows。

```text
计算机硬件 → 操作系统（Windows 或 Linux）→ 应用程序（如 Java 程序）
```

Windows 常见于开发者的个人电脑，Linux 常见于项目服务器，但这不是硬性规定。两者的路径写法也不同，例如 Windows 常见 `C:\Users\...`，Linux 常见 `/home/...`；两者都能运行程序，也都能使用图形界面和命令行。本课程使用 Linux 终端，不要求先学系统管理。

## 1.2 Linux 是什么

严格地说，**Linux 内核**是操作系统的核心部分，负责让程序使用处理器、内存等资源。实际安装或登录的通常是 **Linux 发行版**：它把 Linux 内核、常用命令和其他软件组合成可使用的系统。新人说“这台机器是 Linux”时，通常指某个 Linux 发行版。

Linux 常见于应用服务器、数据库服务器和开发练习环境。此时只需知道“内核”和“发行版”不是同一个概念，不需要学习内核开发。

## 1.3 常见 Linux 发行版

| 发行版 | 本章先怎样认识 |
|---|---|
| Ubuntu | 适合本课程的本地练习环境，WSL2 中可以安装 Ubuntu |
| Rocky Linux | 企业项目可能遇到的发行版 |
| RHEL（Red Hat Enterprise Linux） | 企业项目可能使用的商业发行版 |
| Amazon Linux | 在 AWS 环境中可能遇到的发行版 |

它们都属于 Linux 发行版，但预装软件和配置可能不同。本课程主要以 Ubuntu 和 Bash 作为命令说明参考。基础 Linux 命令可以在其他常见 Linux 环境中练习；涉及 Bash 脚本时，需要使用支持 Bash 的环境。

## 1.4 Linux 与项目开发

为什么 Java 开发者要学 Linux？你可能在 Windows 开发机上编写并运行 Spring Boot 项目，但团队把测试环境中的应用部署在 Linux 上。测试人员报告接口失败时，开发者需要在获准访问的环境中找到程序和日志，才能提供调查证据。

```text
开发机（例如 Windows）：写代码、在本机测试
           ↓ 提交与部署由项目流程完成
应用服务器（可能是 Linux）：运行 Spring Boot 应用
           ↓ 应用按项目配置访问
数据库服务器（可能是另一台 Linux）：保存业务数据
```

“开发机”“应用服务器”“数据库服务器”说的是**用途**，不是三种操作系统；小型练习也可能把应用和数据库放在同一台机器。现在先认清各自角色，不需要在本章部署服务或管理数据库。

## 1.5 GUI、CLI、终端与 Bash

**GUI（图形界面）**让你用窗口、鼠标和菜单操作；**CLI（命令行界面）**让你输入文字命令。Windows 和 Linux 都可以使用这两种方式。

在 Linux 中，**终端**是输入命令和显示结果的窗口；**Shell** 是读取并解释命令的程序；**Bash** 是常见的一种 Shell。它们的关系是：

```text
你在终端输入命令 → Bash（Shell）解释命令 → Linux 运行相应程序 → 终端显示结果
```

终端上形如 `learner@host:~$` 的文字叫**提示符**，表示正在等待输入；复制教材命令时不要把提示符一起输入。

## 1.6 准备练习环境

本章可以先用浏览器体验三条基础命令；准备长期练习时，再选择适合自己的本地环境。

- **浏览器在线 Linux 环境（优先）**：打开 [JSLinux](https://bellard.org/jslinux/) 并选择 Linux 命令行环境，或打开 [WebVM](https://webvm.io/)。个人体验基础环境通常免费，无需注册或安装 Linux。在线环境的发行版和 Shell 不一定是 Ubuntu、Bash；环境也可能重置，不保证练习文件长期保存。
- **WSL2（可选）**：让 Windows 电脑运行 Linux 环境，适合长期开发和练习。可以使用 Ubuntu；安装可能需要管理员权限，具体步骤见 [Microsoft 官方安装说明](https://learn.microsoft.com/windows/wsl/install)。
- **Linux 虚拟机（可选）**：在现有电脑中运行一套独立的 Linux 环境。若教师提供了虚拟机，启动后打开其中的终端即可。

课程练习使用个人或教师提供的环境；实际项目服务器操作需遵循项目权限和手顺。

## 1.7 第一次操作

在刚打开的 Linux 终端中，逐条输入并按回车：

```bash
whoami
pwd
date
```

这三条命令都只读取信息，不会修改文件，也不需要额外参数：

| 命令 | 要回答的问题 | 怎样看结果 |
|---|---|---|
| `whoami` | 当前以哪个用户身份操作？ | 应显示你创建或获分配的 Linux 用户名 |
| `pwd` | 当前位于哪个目录？ | 应显示一个以 `/` 开始的路径，例如 `/home/learner` |
| `date` | 这台环境现在显示什么日期和时间？ | 会显示日期、时间，可能含时区；格式随环境设置变化 |

例如，使用账号 `learner` 的练习环境可能依次显示 `learner`、`/home/learner` 和一行当前日期时间。你的结果不必与示例完全相同；重要的是能指出哪一行回答了哪个问题。若终端提示 `command not found`，先核对命令拼写。

课堂检查：① 服务器一定运行 Linux 吗？② 终端与 Bash 是同一个东西吗？③ `whoami`、`pwd`、`date` 分别回答什么问题？参考：不一定；不是，终端是窗口，Bash 是解释命令的 Shell；分别是用户、目录、日期时间。
