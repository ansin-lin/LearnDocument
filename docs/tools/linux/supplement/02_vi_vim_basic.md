# 选读：Vim 常用编辑操作

本篇承接[第 4 章的最小编辑示例](../04_text_log_shell_basic.md)：已会用 `i` 输入、`Esc` 回到普通模式，以及 `:wq` 保存退出后，再按需学习查找、撤销和行操作。这里只编辑练习副本；真实项目的配置变更仍需遵循作业手顺。

## 准备练习副本

```bash
cd "$HOME/learndoc-linux-lab"
cp -i -- input/app.conf output/app.conf.vim-practice
vim output/app.conf.vim-practice
```

`cp -i` 创建副本，目标已有内容时会询问是否覆盖；`vim` 只打开副本，原始 `input/app.conf` 保持不变。环境没有 Vim 时，可使用已有的 `vi` 练习受支持的操作，不需专门安装软件。

## 查找、撤销与行操作

- 普通模式：打开后的默认状态，用于移动、复制和删除
- 插入模式：按 `i` 进入，输入文字
- 命令行模式：普通模式按 `:`，用于保存、退出和替换

不知道当前状态时按 `Esc` 回到普通模式。以下命令先在练习副本上逐项试用，不必一次记住全部：

| 任务 | 操作 |
|---|---|
| 删除当前行 | 普通模式 `dd` |
| 复制/粘贴行 | `yy`、`p` |
| 撤销/重做 | `u`、`Ctrl+r` |
| 查找 | `/keyword`，再按 `n` |
| 下一行新建并进入插入模式 | `o` |
| 到行尾并进入插入模式 | `A` |
| 到文件开头／末尾 | `gg`／`G` |
| 显示行号 | `:set number` 后回车 |

`yy` 复制当前行，`p` 在光标后粘贴；`u` 撤销最近一次修改，`Ctrl+r` 重做；`/keyword` 搜索文字，`n` 跳到下一个结果。`o`、`A`、`gg`、`G` 在普通模式输入；`:set number` 在命令行模式输入。全文替换属于了解内容：在**新的练习副本**中输入 `:%s/batch/web/g` 并回车，可把文件中的 `batch` 全部替换为 `web`；先确认范围，误操作按 `u` 撤销。真实配置不要未经 Review 就全文替换。

## 修改后核对

把 `mode=batch` 修改为 `mode=web`，保存退出后执行：

```bash
grep '^mode=web$' output/app.conf.vim-practice
diff -u input/app.conf output/app.conf.vim-practice
```

`diff -u` 的差异区应只有一处预期的配置值变化（另外还会显示文件名和上下文）。实际项目修改配置时，应先备份、限定变更范围，并运行项目提供的语法检查；本课程不直接编辑 `/etc`。
`grep '^mode=web$'` 检查文件里是否存在完整的目标行；`^` 和 `$` 分别限定行首、行尾。`diff -u 旧文件 新文件` 显示差异，`-` 开头是旧内容，`+` 开头是新内容；有差异时它通常返回状态 1，不表示比较命令损坏。

## 常见问题

- 无法输入：按 `i` 进入插入模式。
- 无法退出：按 `Esc`，再输入 `:q`；有未保存修改时选择 `:wq` 或确认放弃后 `:q!`。
- 文件只读：不要用 sudo 强行打开；确认路径、权限和作业权限。
- 修改过多：退出不保存，重新复制练习副本。

1. 在副本中修改一个配置值。
2. 使用 `diff -u` 查看差异，确认只改动预期字段。

