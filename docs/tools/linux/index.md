# Linux 命令课程

本课程面向进入日本 Web 系统或批处理项目的程序员。第 01 章可先用浏览器在线 Linux 环境体验；持续练习建议使用个人或教师提供的 Linux 环境，命令说明主要参考 Ubuntu 和 Bash。

课程目标不是培养服务器管理员，而是让你掌握文件、权限、日志、进程和网络的基本操作，读懂 Java Web 应用部署过程，并根据进程、端口、HTTP 与日志证据初步调查故障。

## 完成后能够做什么

- 确认当前用户、主机、目录和 Linux 发行版
- 在限定目录内创建、复制、移动、搜索和查看文件
- 读懂文件所有者、所属组和 `rwx` 权限，定位常见权限错误
- 区分 JAR 文件、Java 进程与 systemd 服务，读取状态；选做安全结束自己启动的练习进程
- 在项目指定的主机上，用 `ss`、`curl` 分别核对监听端口与已知测试接口
- 使用 `grep`、`less`、`tail` 和 `journalctl` 阅读项目允许访问的日志
- 读懂 SSH 登录、SCP 上传及 Java JAR 部署流程，并区分进程、监听端口与 HTTP 响应
- 根据模拟接口与日志证据判断故障，区分已确认事实和原因候选
- 通过补充阅读使用 Vim 完成小范围文件修改，并比较修改前后的差异
- 读懂当前用户的 cron 条目；在独立练习环境中选做定时任务实验
- 按日本项目常见格式提交调查命令、结果、影响范围和残课题

## 主线操作边界

第 1～5 章主要在个人 Bash 环境练习。第 6 章的网络命令与模拟访问故障、第 7 章的部署流程阅读、第 8 章的模拟证据调查，**都不要求独立服务器**。SSH/SCP 实际连接只在教师提供并授权的练习主机上尝试；本课程不要求软件安装、服务配置、发布或回退实操。真实项目服务器必须遵循手顺、权限与审批。

以下内容仍不要求新人 PG 独立管理：

- 网络设备、路由、防火墙和 DNS 管理
- 生产软件包升级和仓库管理
- 生产 systemd 服务创建、开机启动设置及未经授权的启停
- 分区、格式化、挂载和存储扩容
- 用户创建、密码管理和 sudo 策略修改

遇到这些任务时，应先确认作业手顺、权限和负责人，不在共享环境中自行尝试。

## 操作约定

- 第 01 章先认识环境并执行三条只读命令；第 02 章建立 `~/learndoc-linux-lab`，此后普通练习统一在该目录下完成。
- 命令执行前先运行 `pwd`，删除或修改前再运行 `ls -la -- <目标>`。
- 文中的 `<path>`、`<pid>` 和 `<keyword>` 是占位符，必须替换。
- 命令块中不包含终端提示符（如 `$`）；只复制命令本身。`<...>` 不能原样输入。每条命令后的说明会解释用途、当前参数和应观察的结果。
- 不在生产环境执行练习，不修改 `/etc`、`/var` 或其他用户目录。
- 命令失败后先记录命令、错误信息和退出状态，不用 sudo 强行绕过。

```bash
printf 'exit_status=%s\n' "$?"
```

退出状态 `0` 通常表示成功，非 `0` 表示失败或未找到匹配，具体含义以命令说明为准。
