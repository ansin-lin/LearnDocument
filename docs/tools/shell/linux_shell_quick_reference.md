# Linux 与 Bash 新人速查表

本页供学完 [Linux](../linux/index.md) 和 [Bash](index.md) 后回看。示例统一在 Bash、普通用户、`~/learndoc-linux-lab` 下理解；`<...>` 必须替换，不是可以原样执行的命令。写入、覆盖、删除、结束进程的操作只对自己的练习对象执行。每条只列本课程用到的写法，完整解释见对应章节。

## 环境与远程连接

- `pwd`：显示当前目录；写法 `pwd`，无常用选项；切换目录后核对位置；只读。
- `whoami`：显示当前账号；写法 `whoami`，无常用选项；确认调查身份；只读。
- `hostname`：显示当前主机名；写法 `hostname`，无常用选项；防止在错误服务器操作；只读。
- `id`：显示 UID、GID 和附加组；写法 `id`，本课不需选项；排查权限；只读。
- `groups`：列所属组；写法 `groups`，本课不需选项；判断组权限；只读。
- `cat /etc/os-release`：读取发行版资料；`cat 文件` 中的文件是输入参数；核对环境版本；不修改系统文件。
- `printenv`：列环境变量；写法 `printenv`，无必需选项；比较项目环境；输出可能含秘密，不整份提交。
- `command -v java`：查命令解析到哪里；`command -v 命令名`；排查 `command not found`；未找到返回非 0，不自行安装。
- `ssh -p 2222 learner@192.0.2.10`：远程登录；`ssh [-p 端口] 用户@主机`，不写 `-p` 通常使用 22；只连接授权主机并核对指纹；示例地址不可连接，警告不能忽略。

## 文件、目录与文本

- `cd "$HOME/learndoc-linux-lab"`：切换目录；`cd 路径`；进入练习目录；先用 `pwd` 验证，不猜项目路径。
- `ls -lah -- input`：列内容；`ls [选项] [路径]`，`-l` 详细、`-a` 隐藏、`-h` 易读大小、`-t` 按时间、`-d` 看目录自身；核对文件状态；只读。
- `mkdir -p output/archive`：创建目录；`mkdir [-p] 路径`，`-p` 允许补父目录；准备练习输出；在目标已存在时核对内容。
- `cp -i -- 源 目标`：复制；`cp [选项] 源 目标`，`-i` 覆盖询问、`-p` 尽量保留属性、`-R` 递归目录；先做副本；核对目标以免覆盖或大范围复制。
- `mv -i -- 源 目标`：移动或改名；`mv [选项] 源 目标`，`-i` 询问覆盖、`-n` 不覆盖；整理练习文件；移动后旧路径不再存在，`-n` 跳过时再用 `ls` 核对。
- `touch output/demo.txt`：创建空文件或更新修改时间；`touch 文件`；准备删除练习；只用于自己目录。
- `rm -i -- output/demo.txt`：删除文件；`rm [-i] 文件`，`-i` 逐个询问，`-r` 递归、`-f` 强制仅了解风险；清理已确认练习文件；不可直接恢复，不执行 `rm -rf` 练习。
- `rmdir output/empty`：删除空目录；`rmdir 目录`；清理空练习目录；非空会拒绝，不用递归删除代替。
- `cat input/app.conf`：显示短文本；`cat 文件`；核对配置副本；大日志改用 `less` 或 `tail`。
- `less input/app.log`：分页阅读；`less 文件`，按 `/词` 搜索、`q` 退出；查看长日志；只读。
- `head -n 2 input/app.log`：看开头；`head -n 行数 文件`；核对文件头；只读。
- `tail -n 100 input/app.log`：看结尾；`tail -n 行数 文件`，`-f` 跟随已打开文件、`-F` 按名称重开；调查新日志；跟随后按 `Ctrl+C`。
- `grep -n -C 1 'ERROR' input/app.log`：按行搜索；`grep [选项] 模式 文件`，`-n` 行号、`-i` 忽略大小写、`-E` 扩展正则、`-F` 固定文字、`-v` 排除、`-c` 计数、`-A/-B/-C` 上下文、`-r` 递归；调查错误；状态 1 是无匹配，递归范围要受限。
- `find input -maxdepth 2 -type f -name '*.log' -print`：找文件；`find 起点 条件`，`-type f` 普通文件、`-name` 名称、`-maxdepth` 深度、`-mtime -1` 最近约 24 小时；找练习日志；不要从 `/` 大范围搜索。
- `wc -l input/app.log`：统计行数；`wc -l 文件`；核对输出记录数；管道左侧失败时单看数字会误导。
- `sort`：对输入行排序；`sort 文件` 或接管道；为 `uniq` 准备相邻相同项；不自动改原文件。
- `uniq -c`：计数相邻相同行；`uniq -c 文件` 或接 `sort` 输出；统计重复级别；未排序时相同内容可能分散。
- `diff -u 旧文件 新文件`：显示统一格式差异；`-u` 给上下文；Review 配置修改；有差异通常返回 1，不等于命令坏了。
- `tar -czf output/input.tar.gz input`：归档并 gzip 压缩；`tar -tzf 归档` 查看成员，`tar -xzf 归档 -C 空目录` 解压；`-c` 建、`-t` 看、`-x` 解、`-z` gzip、`-f` 文件、`-v` 显名；打包已脱敏练习资料；解压前先查看成员，仅解到独立空目录。

## 权限、进程与资源

- `chmod 600 output/demo.conf`：改自己文件权限；`chmod 模式 路径`，`600` 仅所有者读写、`u+x` 加所有者执行；练习权限；不对共享文件递归操作。
- `chown 用户:组 路径`：改变属主／组；只要求能读懂既有命令；通常需额外权限，不在共享环境练习。
- `sudo 命令`：按策略以其他身份运行；只了解含义；遇权限错误先报告，不用它绕过作业权限。
- `ps -ef`：列进程；`ps [选项]`，`-e` 全部、`-f` 完整格式，`ps aux` 是另一常见写法；调查 Java 进程；只读，不能凭名称直接结束。
- `pgrep -af java`：按进程名或完整命令行搜索；`pgrep [-a] [-f] 名称`，`-a` 显命令、`-f` 匹配全命令；定位候选 PID；核对账号与命令，别批量 kill。
- `kill -TERM PID`：发送正常结束请求；`kill -TERM 已确认PID`；仅结束自己刚启动的练习进程；未知服务进程不能照做。
- `top`：实时看 CPU、内存和进程；写法 `top`，按 `q` 退出；观察资源；只读，不能仅凭瞬时数字定根因。
- `uptime`：看运行时间与负载概况；写法 `uptime`；记录主机状态；负载高需更多证据。
- `free -h`：看内存概况；`-h` 易读单位；排查资源现象；不要自行调优。
- `df -h "$HOME"`：看所在文件系统空间；`-h` 易读单位；排查磁盘不足；不是目录大小。
- `du -sh "$HOME/learndoc-linux-lab"`：汇总目录占用；`-s` 汇总、`-h` 易读；调查练习文件大小；大型目录遍历可能较慢。

## Web、日志与调度（只读）

- `ss -lntp`：看本机 TCP 监听端口；`ss [选项]`，`-l` 监听、`-n` 数字、`-t` TCP、`-p` 进程；核对预期端口；权限不足可能看不到进程。
- `curl --connect-timeout 3 --max-time 10 -i URL`：发送 HTTP 请求；`-i` 带响应头、`-I` HEAD、`-v` 详细跟踪；检查已知测试接口；HTTP 500 不等于 curl 退出状态非 0，跟踪可能含秘密。
- `systemctl is-active 服务名`：读 systemd 服务活动状态；`systemctl status 服务名 --no-pager` 看详细状态；调查已知服务；无 systemd 时跳过，不执行启停。
- `journalctl -u 服务名 --since 时间 --until 时间 --no-pager`：读已知服务日志；`-u` 服务、时间选项限范围；关联障害时间；权限和日志位置依项目而异。
- `crontab -l`：列当前用户计划任务；`-l` 只读，`-e` 会修改且仅选学；读夜间作业时间；看不到其他用户任务，不随意编辑。

## Bash 脚本与语法

以下有些是 Bash **语法**，不是外部 Linux 命令。例子中的 `check_log.sh` 位于练习目录。

- `#!/usr/bin/env bash`：文件首行指定直接执行的解释器；无参数；给 `.sh` 脚本；不是在终端单独执行的命令。
- `bash check_log.sh ...`：显式用 Bash 运行文件；`bash -n 文件` 只查语法、`bash -x 文件 参数` 执行跟踪；自测和排错；`-x` 可能泄露参数。
- `log_file='input/app.log'`：当前 Shell 变量赋值；等号两边无空格；保存文件路径；读取时写 `"$log_file"`，避免分词。
- `export APP_ENV='test'`：把变量传给随后启动的子进程；`export 名=值`；项目环境配置；不得把真实密钥写进脚本。
- `$0`、`$1`、`$#`、`"$@"`：分别是脚本名、第一参数、参数个数、逐个保留全部参数；在脚本中读取；参数缺失先校验。
- `$?`：上一条命令的退出状态；紧接命令读取或存入变量；区分成功、无数据和失败；任何后续命令都会覆盖它。
- `$(命令)`：先执行括号内命令并取 stdout；如 `"$(pwd)"`；构造路径或统计值；关键命令失败状态仍需检查。
- `>`、`>>`、`<`：分别覆盖输出、追加输出、把文件作 stdin；如 `grep ... > output/result.txt`；保存结果；覆盖前核对目标。
- `2>`、`2>&1`：保存 stderr、或把它指向 stdout 当前目标；常用于作业日志；顺序会影响去向，可能泄露错误内容。
- `|`：前一条 stdout 交给后一条 stdin；如 `grep ... | wc -l`；快速统计；前段失败可能被隐藏。
- `tee [-a] 文件`：同时显示并保存 stdout，`-a` 追加；保留自测输出；默认覆盖，且不会自动收集 stderr。
- `if [[ 条件 ]]; then ... elif ... else ... fi`：按条件选择分支；`-f` 普通文件、`-r` 可读、`-z` 空串；输入检查；每条分支应有可核对结果。
- `for x in 列表; do ... done`：逐项循环，`x` 每轮换值；处理 ID 列表；路径参数用 `"$@"` 保边界。
- `while IFS= read -r line; do ... done < 文件`：逐行读取直到 EOF；日志逐行处理；`IFS=` 保空白、`-r` 保反斜杠，避免按空格拆行。
- `case 值 in 模式) ... ;; esac`：按固定模式分支；了解即可，适合读既有参数解析；新增分支前核对默认情况。
- `name() { ...; }`：定义函数，调用时写函数名；`local` 把变量限制在函数内；复用校验／输出；函数参数是调用时的 `$1`、`$2`。
- `return 状态` / `exit 状态`：前者结束函数，后者结束脚本；向调用者传状态；不要把非 0 都写成同一种错误。
- `set -u` / `set -o pipefail`：防未定义变量和管道早段失败被掩盖；放脚本前部；仍需显式错误处理，`set -e` 不是万能方案。
- `mktemp output/.check.XXXXXX`：建立唯一临时文件；模板末尾的 X 由工具替换；安全写结果；限定目录并清理。
- `trap cleanup EXIT`：脚本退出时调用清理函数；用于临时文件；清理目标必须是本脚本确认创建的文件。

先按场景回到正文完成一次实操，再用本页查写法；不要把这份速查表当作可在生产服务器逐行执行的脚本。
