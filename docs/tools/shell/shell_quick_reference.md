# Shell Batch 速查表

供学完 [八章主线](index.md) 后回看；只汇总 Bash/Batch 写法，Linux 命令细节回到 [Linux 课程](../linux/index.md)。`<...>` 表示替换项，不可原样执行。凡覆盖/移动/删除均限个人练习副本。

| 写法 | 含义 | 本课应用与提醒 |
|---|---|---|
| `#!/usr/bin/env bash` | 直接执行时选择 Bash | 须在首行；`bash file.sh` 显式指定解释器 |
| `bash -n file.sh` | 只查语法 | 不运行业务；通过不代表测试通过 |
| `bash -x file.sh` | 执行并跟踪 | 可能暴露参数与秘密 |
| `name='value'`、`"$name"` | 赋值、保留一个参数读取 | 等号无空格；路径必加引号 |
| `$0`、`$1`、`$#`、`"$@"` | 脚本名、第一参数、参数数、全部参数 | 先查数量再读必需参数 |
| `${1:-}` | 参数缺失时用空串 | 便于展示，不等于已校验 |
| `export APP_ENV=test` | 传环境变量给子进程 | 配置依项目手顺；不硬编码凭据 |
| `$(command)` | 获取命令的 stdout | 关键命令仍要检查失败 |
| `[[ -f "$f" ]]`、`[[ -s "$f" ]]` | 普通文件、非空文件检查 | 非空不证明 CSV 格式正确 |
| `if ...; then ...; else ...; fi` | 条件分支 | 用于参数、文件、返回码 |
| `case "$x" in ... esac` | 固定模式分支 | 配置种类、后缀判断 |
| `for x in "$@"; do ...; done` | 遍历参数 | `"$@"` 保留各参数边界 |
| `while IFS= read -r line; do ...; done < file` | 逐行读取 | 会看懂；复杂 CSV 不在 Shell 解析 |
| `name() { ...; }`、`return 1` | 函数定义、结束函数 | `exit 1` 才结束整个脚本 |
| `java -jar app.jar 日期 文件` | 同步调用 Java | 不加 `&` 才能直接等待业务结果 |
| `status=$?` | 保存刚结束命令的状态 | 必须紧跟 Java 调用 |
| `> file`、`>> file`、`< file` | 覆盖、追加、作为输入 | `>` 会覆盖原内容 |
| `2> err`、`2>&1` | 单存 stderr、合入当前 stdout | 重定向顺序会改变结果 |
| `|`、`tee -a file` | 管道；同时显示并追加 | 默认管道状态可能隐藏左侧失败 |
| `set -u`、`set -o pipefail` | 未定义变量与管道失败检测 | 不代替显式错误分支 |
| `crontab -l` | 只读查看当前用户 cron | 不等同 JP1/AJS 配置 |

本案例的脚本结束码是 0 成功、2 参数、3 输入/JAR、4 输出准备、10 Java、11 归档；这只是[案例接口](08_batch_project_practice.md)，真实项目看详细设计书。旧日志调查脚本另见[附录](appendix/check_log.md)。
