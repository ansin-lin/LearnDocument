# 销售日次取込：单体测试证据记录样式

本页是**示例证据和填写样式**，不是学员实际测试的替代品。测试要在个人副本中从明确的开始状态逐例运行，真实输出、执行时间与路径以本人环境为准。模拟 Java 不写数据库，故无法作为真实 Spring Batch 业务结果的证据。

| 项目 | 记录 |
|---|---|
| 对象 | `run_sales_import.sh`（或学员提交的 `my_run_sales_import.sh`） |
| 环境 | Linux Bash / GNU date / JDK 17+；填写实际版本 |
| 版本 | 填写修改文件的提交号或保存时间 |
| 前提 | 个人副本；JAR 已由源码构建；各用例重置输入/归档状态 |

## 填写示例：T01 正常系

**命令**：`bash run_sales_import.sh 20260901`，紧接记录退出码。**预期**：0；Java 输出 `rows=2`；原输入移到 `archive/`；日志包含 `SUCCESS`。**示例实际**：`status=0`，日志依次有 `START`、`MOCK_IMPORT date=20260901 rows=2`、`SUCCESS`；`input/sales_20260901.csv` 不存在，`archive/sales_20260901.csv` 存在。判定：通过。日志中的绝对路径由运行环境决定。

## 填写示例：T05 Java 异常系

**准备**：在个人副本把 `testdata/sales_20260903_bad.csv` 复制为 `input/sales_20260903.csv`。**命令**：`bash run_sales_import.sh 20260903`，紧接记录退出码。**预期**：10；输入保留；日志出现数据错误，无 `SUCCESS`。**示例实际**：`status=10`；日志有 `ERROR invalid CSV data at row 2` 与 `ERROR java_status=10`；输入仍在 `input/`，无同名归档。判定：通过。
